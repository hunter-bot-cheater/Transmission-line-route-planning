# 合成栅格搜索几何对照

## 实验设置

使用固定的 61×81 合成栅格，像元间距 30 米。四张地图分别为水平直线均匀面、斜向均匀面、带缺口的硬障碍墙和高代价带。没有读取 DEM、OSM、历史线路或真实端点；路线只由合成代价栅格生成。

对比生产 8 邻域 A*、同邻域 Dijkstra、精确积分 16 邻域 A* 和代价感知 Theta*。统一用分段常数栅格上的精确线积分复核路径代价；硬禁行格采用保守 supercover 检查。每种方法先预热一次，再以轮换顺序测量五次，报告耗时中位数与四分位距；这是本机小栅格的相对参考。

## 结果

| 地图 | 8 邻域 A* | Dijkstra 8 邻域 | 精确 16 邻域 A* | 代价感知 Theta* |
|---|---:|---:|---:|---:|
| 均匀水平面 | 2280；1.47 ms (IQR 0.06)；77 点 | 2280；40.15 ms (1.38)；77 点 | 2280；7.10 ms (0.07)；77 点 | 2280；9.53 ms (0.17)；5 点 |
| 均匀斜向面 | 2631.3；1.78 ms (0.03)；68 点 | 2631.3；46.16 ms (2.38)；68 点 | 2540.5；37.94 ms (0.19)；51 点 | 2508.0；42.41 ms (0.86)；2 点 |
| 硬障碍墙 | 2603.1；11.86 ms (0.13)；77 点 | 2603.1；39.90 ms (0.90)；77 点 | 2464.1；63.19 ms (0.88)；51 点 | 2409.7；102.33 ms (1.78)；3 点 |
| 高代价带 | 2677.6；11.00 ms (0.05)；77 点 | 2677.6；44.25 ms (1.17)；77 点 | 2549.4；63.28 ms (1.54)；53 点 | 2534.9；105.33 ms (1.16)；5 点 |

代价单位为 cost·m，均匀面上的 cost=1，因此数值也等于米。耗时括号中为 IQR 毫秒。

四种方法在四张地图上都通过了硬约束检查。斜向均匀面上，8 邻域结果比欧氏直线下界高约 4.9%，16 邻域约高 1.3%，Theta* 达到直线下界；这直接显示了栅格方向离散造成的代价。障碍和高代价带场景中，16 邻域与 Theta* 得到较低的共同连续积分成本；Theta* 在这两张地图上成本最低、折点较少，但较长视线检查带来更高耗时。16 邻域在障碍图上的转角数较多，说明较长栅格边本身不等于平滑塔位布局。

## 可以得出的结论

- A* 与 Dijkstra 在同一 8 邻域图上给出相同代价；启发式主要减少搜索工作量，不增加地理信息。
- 四种方法共享同一积分目标，但搜索可行路集不同；只有 8 邻域 A* 与 Dijkstra 是同一搜索图上的算法对照。
- 8 邻域方向限制会在斜向均匀图中留下额外路长；16 邻域和 any-angle 可缓解这种离散效应。
- Theta* 在这四张小图上表现较好，但基础 Theta* 对非均匀成本没有全局最优保证。该实验只证明这组输入上的搜索性质。
- 这组运行中的 Theta* 和 16 邻域计算都比生产 8 邻域 A* 慢；真实大栅格需要先做资源预检。四张手工地图不能确定大区域、不同分辨率或其他地形分布上的稳定性能排序。

该结果不用于根据历史线选择算法或调参，也不证明任何实际线路的贴合度或工程可行性。下一轮应扩大合成场景和分辨率扰动；若要进入架空线塔位规划，需要可核实的电压、塔型、档距、导线和净空参数。
