# 加权 A* 合成基准复测

本实验只评估 raster A* 的搜索耗时与离散目标代价，不加载历史线路或参考线。脚本在 35 米像元的三个合成代价场中，针对三组固定端点比较启发权重 `1.00 / 1.05 / 1.10 / 1.20`；每组每个权重先预热一次，再以固定随机种子轮换顺序运行三次。重复计时先按场景和端点配对取中位数，再汇总 9 组场景—端点组合；路径代价回退按每组重复测量中的最大值汇总。筛查门槛是暂定工程筛查值，不是统计置信结论。

| 启发权重 | 搜索失败 | 硬约束违规 | 相对目标代价 P95 / 最大 | 中位加速比 | 筛查结果 |
|---:|---:|---:|---:|---:|---|
| 1.00 | 0 | 0 | 0% / 0% | 1.00× | 对照 |
| 1.05 | 0 | 0 | 0% / 0% | 0.61× | 未通过 |
| 1.10 | 0 | 0 | 0% / 0% | 0.62× | 未通过 |
| 1.20 | 0 | 0 | 0% / 0% | 0.63× | 未通过 |

这里的加速比定义为 `权重 1.0 搜索耗时 / 当前权重搜索耗时`。所有候选路线在这 9 组场景—端点组合上的积分目标与基准相同，但加权搜索没有带来速度收益，反而更慢；因此不建议把它用于默认规划。权重 `1.0` 仍为生产默认，加权模式仅保留为显式诊断选项。

为使加权启发式具有标准的 `w` 代价上界，基础 A* 现会在发现更低代价时重新打开已扩展节点，并忽略队列中的过期条目。此保证仅在非负边代价、基础启发式可采纳时成立，并针对函数实际使用的搜索端点；当前入口可能把禁行像元上的端点吸附到附近有效像元。该界只针对原始搜索路径目标，不覆盖平滑、端点恢复或后续路线处理。重开节点可能增加搜索工作量，本组基准确实没有显示出加速。

逐次运行数据保存在 [`benchmark_results/weighted_astar_synthetic_20261024.json`](benchmark_results/weighted_astar_synthetic_20261024.json)，重跑脚本时另生成 `outputs/optimization_loop_20261024/weighted_astar_synthetic/results.json`。本实验使用人工地形和禁行栅格，只测裸搜索；不能据此判断对真实线路的贴合度、杆塔档距可行性、导线净空或工程造价。
