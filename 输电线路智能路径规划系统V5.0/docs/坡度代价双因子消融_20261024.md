# 坡度代价双因子全流程消融（2026-10-24）

## 问题与预设方案

生产 A* 目标同时包含栅格坡度面惩罚和相邻像元边的地表高差惩罚。为测量两项各自的敏感度及交互，选 TW173（长度/走廊偏差都较大的案例）和 TW58（长度接近但走廊仍偏移的案例），冻结 2×2 参数组：

| 方案 | `terrain_slope_weight` | `grade_penalty_weight` |
|---|---:|---:|
| 基线 | 0.75 | 1.0 |
| 关闭边级坡度 | 0.75 | 0 |
| 关闭栅格坡度 | 0 | 1.0 |
| 同时关闭 | 0 | 0 |

除这两项外，DEM、端点 CSV、OSM 缓存、官方灾害图层、其余成本权重、A* 搜索模式、DEM 窗口和输出流程保持一致。`grade_penalty_weight` 同时影响边级 A* 代价和后续平滑接受条件，因此本实验评估的是**完整规划流水线的因子敏感性**，不是孤立的 A* 内核实验。

## 参考线隔离与复现

四组候选生成时，`--real-dir` 指向空的 `reference_quarantine` 目录；每个 `run_summary.json` 都记录两条线路为 `reference_missing`。候选生成脚本只读案例 CSV 中的起终点坐标，不读取参考 Shapefile。四组完成后先将参数、源码、运行日志、输入、候选路线和评分脚本等 295 个文件写入 `candidate_manifest.json` 并记录 SHA-256，再由 [版本控制下的评分工具](../tools/score_grade_penalty_2x2.py)校验哈希、读取参考线并评分；评分报告记录清单与评分脚本哈希，评分结果只在评分结束且冻结文件复核通过后写出，且不按评分选择权重或生产路线。端点仍取自历史线路端点，因此这是固定端点诊断，不是独立站端盲测。

运行顺序和文件：

1. 使用与下列基线命令相同的输入，输出到 `outputs/grade_penalty_2x2_20261024/baseline`，并把 `--real-dir` 指向 `outputs/grade_penalty_2x2_20261024/reference_quarantine`。
2. `outputs/grade_penalty_2x2_20261024/run_remaining.ps1` 生成其余三组。
3. 运行 `D:\python\python.exe -B outputs\grade_penalty_2x2_20261024\freeze_candidates.py` 冻结并校验候选。
4. 运行 `D:\python\python.exe -B tools\score_grade_penalty_2x2.py` 做候选间诊断和一次性参考线后验评分。

```powershell
& 'D:\python\python.exe' -B -m transmission_path_planner `
  --dem 'data\taiwan_dem_35m_georef_fixed.tif' `
  --osm-cache-dir 'D:\大创\V5_final\data\downloaded' `
  --real-cases-csv 'outputs\ablation_tw58_tw173_20261024\cases.csv' `
  --real-dir 'outputs\grade_penalty_2x2_20261024\reference_quarantine' `
  --out-dir 'outputs\grade_penalty_2x2_20261024\baseline' `
  --no-vin --no-ppp --max-side 4096
```

完整候选输入/输出哈希见本地忽略目录 `outputs/grade_penalty_2x2_20261024/candidate_manifest.json`；后验分数和参考数据哈希见 `posthoc_scores.json`。这两项数据产物保留在当前工作区，不提交原始数据或运行输出。

## 下一步判断

目前没有可追溯的电压等级、塔型、导线、档距、弧垂净空、跨越许可和塔位工程约束，35 米 DEM 的来源与垂直基准也待核验。继续看这两条参考线调整坡度权重会形成历史线调参。下一轮应优先核验更高质量 DTM、人口/法定约束数据和工程输入；在输入到位前保持生产默认值，继续评估多目标候选走廊，并把候选质量、工程可行性和历史线后验评分分开报告。
