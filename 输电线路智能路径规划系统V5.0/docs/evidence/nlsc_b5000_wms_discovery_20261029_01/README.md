# 国土测绘中心 1:5,000 WMS 可用性核查

核查日期：2026-10-29

来源：内政部国土测绘中心 WMS，图层 `B5000`（1/5000 基本地形图），PNG 输出。

一次 GetMap 请求无需认证并成功返回；GetCapabilities 返回 `B5000`、`queryable=0`，因此它提供的是渲染图像，不能查询线路属性或下载线路矢量要素。国土测绘中心 FAQ 另确认 1:5,000 向量图包含公共事业网络（高压线塔及高压电线）。

单幅本地样图是围绕深美站端公开案例坐标发出的 GetMap 请求，用于确认服务可访问并检查地图表现；返回 HTTP 200，图面标注 `NLSC 1/5000 2023`。样图保留在本地工作区，不纳入 Git 提交；没有从图像中数字化线路，也没有将历史线路输入规划器。

NLSC 条款允许带来源信息公开显示，但明确禁止大量下载，且静态地图图片不转移著作权；FAQ 列出的开放 WMS 图层清单不含 B5000。因此这里仅记录一次单幅响应，不将其描述为可自由再分发的开放数据，不批量下载或缓存图砖。

GetMap 请求范围：EPSG:4326，BBOX `121.7035,24.6397,121.7135,24.6497`，1024×1024 像素，图层 `B5000`。地图图像内保留了来源标记。

后续目视对照时，应先冻结规划路线，再通过官方网页/WMS查看对应范围。若要获得可计算的官方线路中心线，应申购对应图幅的 SHP/DWG/DXF；该路径的费用和限制条件见 `../osm_route_reference_source_audit_20261029.md`。
