# 台电电杆与输电系统电杆数据源审计

审计日期：2026-10-30

## 发现

### 台电全台电杆坐标及桿號

- 官方目录：[台灣電力公司電桿坐標及桿號](https://data.gov.tw/dataset/33305)
- 提供机关：台湾电力股份有限公司；开放政府资料授权第一版；目录标注每月更新，元数据更新时间为 2026-06-18。
- 字段包括县市、行政区、乡里、图号座标、形式、桿號、TWD_97_X、TWD_97_Y；目录描述为各区处电杆坐标和编号。
- 目录所链接的 CSV 资源为 `https://service.taipower.com.tw/data/opendata/apply/file/d077006/all.csv`。

**规划用途判定：暂不接入。**目录未说明该点集仅含输电塔/输电线路侧设施，也没有电压、回路、线路编号、塔间连接关系、结构高度或档距字段。它可能混有配电杆点位，不能由“台电电杆”直接推断为输电设施，也不能将点位连线成输电走廊。它可作为后续站端/设施核验的候选索引，但需先核验“形式”编码定义、记录坐标质量与输电/配电分类。

### 台南市公共管线图资中的输电系统电桿

- 官方目录：[臺南市公共管線圖資－輸電系統電桿](https://data.tainan.gov.tw/DataSet/Detail/b2d312c5-99e9-42af-a512-514634066443)
- 官方资源页：[110年輸電系統電桿 SHP](https://data.tainan.gov.tw/Resource/f5f7257d-418f-4972-811b-a082635daca8)
- 目录标注为 ShapeFile、UTF-8、政府资料开放授权条款第一版，空间范围台南；资源元数据更新时间为 2025-12-29。
- 属性含 `PoleNo`、`Agency`、`OpType`、`Length`、`Material`、`UseStat`、`Status` 等，可用于设施语义与状态检查。
- 市府说明公共管线图资由辖区管线单位提供、仅供参考，详细资料应洽管线单位。资源页列出的坐标系统值为 `0`，使用前必须从实际 `.prj`/源文件核验坐标基准。

**规划用途判定：仅可作为台南局部的后验抽查候选。**数据名指向输电系统电桿，比全台通用电杆数据更具体，但它不是完整线路中心线，覆盖范围有限，且坐标系统和现势性需从原始文件确认。若后续用于独立评估，必须先冻结不读取历史线的规划候选，再下载、哈希、确认投影和字段，并报告其局部覆盖；不能用这些电桿反推整条线路或宣称代表全台实际线。

## 获取状态与边界

本次只核对官方目录元数据，没有将数据下载进规划器。对台电 CSV 的 HTTPS 抽样请求因服务端证书校验失败而停止；没有绕过证书检查。台南 SHP 资源页可见，但本次没有获取原始压缩包。

这两类资源尚不能补足权威站端线路侧接入点、全线塔位连接拓扑、导线弧垂/净空或工程许可资料。因此当前线路结果仍需标注为地形与约束筛查；不得把“有电杆点位”表述为线路工程可行性验证。

## 对后续评估的操作建议

1. 先从台电目录/API 查清“形式”编码定义及电杆/输电塔分类，再评估全台点数据是否足以筛选输电设施。
2. 对台南 SHP，先检查 `.prj`、几何类型、字段空值、编号重复和空间范围；只选与已授权参考案例有交集的子区做后验审查。
3. 每个案例保存源 URL、获取时间、许可、原文件哈希、坐标转换、过滤规则和候选路线冻结时间；规划阶段不得读取历史线或塔位点集。
4. 只有具备塔位与连线顺序/线路编号的权威资料，才可用于估计真实跨距或搭建工程校核图；单独的电杆点集不满足此条件。
