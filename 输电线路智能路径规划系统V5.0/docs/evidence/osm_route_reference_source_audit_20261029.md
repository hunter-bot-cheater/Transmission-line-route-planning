# 台湾输电线路公开参考数据核查

核查日期：2026-10-29

## 结论

目前找到可直接获取的线路几何，是 OpenStreetMap（OSM）上的 345 kV「深美～冬山線」。另发现国土测绘中心 B5000 WMS 可在线渲染 1:5,000 基本地形图，适合规划冻结后的有限目视核验。OSM 可以作对照线，不能当作官方竣工中心线或测量真值；它由社区维护，没有测绘精度承诺，也不能放入规划代价面、候选走廊或搜索图。

本轮没有找到台电公开的、同时带有站侧接入点、塔序及完整输电线路中心线的全台数据。台电公开电桿坐标表没有输电回路、电压、塔序或站间关联字段。内政部国土测绘中心 1:5,000 向量图是目前最好的官方候选：官方说明数据含高压线塔与高压电线，并提供 SHP/DWG/DXF；但具体线路所在图幅、字段、开放状态与购买条件仍需逐幅核实。

## 来源限制与交叉核验

- OSM 台湾电网页面列有 161 kV 和 345 kV 输电线路。OpenInfraMap 根据 OSM 统计约有 2,223 km 线路落在 330–549 kV 档、2,250 km 落在 132–219 kV 档。这是地图已绘制长度，不代表官方完整度或位置精度。
- 台电研究资料确认存在 345 kV 深美～冬山线，并列出 #87–#97 号监测铁塔；这独立佐证线路名称和塔号范围，但不提供路线坐标。
- 台电公开电桿 CSV 提供坐标、杆型及杆号，没有回路或铁塔编号字段；此前的字段审计已判定它不适合作为本线路的塔位真值。
- 国土测绘中心 1:5,000 向量成果是目前最佳官方路线核验候选。FAQ 说明图层含高压线塔和高压电线，可申请 SHP/DWG/DXF。本轮未购买数据，目标图幅和属性结构尚未确认。

### 官方高压线图资的实际取得条件

继续核查国土测绘中心供图页面后，确认 1:5,000 数值地形图确实含“公共事业网络（高压线塔及高压电线）”向量图层，格式包括 SHP、DWG 或 DXF。它比 OSM 更适合作为本线路的官方事后核验材料，但官网并未将该线路图层列为免申请免费开放数据：电子商城要求以自然人、行动自然人或工商凭证登入；1:5,000 像片基本图数值档按图幅计费，首次非加值型每幅新台币 150 元、更新 75 元、加值型 600 元。页面另列“机关公文申请（限制公开）”及“不限（非限制公开）”两种供给情形，若申请到限制公开成果，须签署管制同意书，并按指定用途保管、限制转交及在无继续使用需要时销毁。

因此暂不自动下单或提交申请，也不把通用电子地图的公开图砖误认为包含可下载的高压塔/高压线矢量层。待确认目标线路所需图幅、成果是否属限制公开、字段含义和精确费用后，才可确定能否作为可分发的独立参考数据。官方 FAQ 的图层说明、供给费用和管制同意书见下方来源。

另经官方 WMS 服务目录及 GetCapabilities 核查，`B5000`（1:5,000 基本地形图）图层可经 `https://wms.nlsc.gov.tw/wms` 返回 PNG，图层 `queryable=0`，不提供要素属性查询或矢量下载。一次小范围请求返回 HTTP 200，地图标注为 NLSC 1:5,000 / 2023。官方服务条款允许附来源信息公开显示，禁止大量下载，并说明静态地图图片不转移著作权；FAQ 列出的开放 WMS 图层中没有 B5000。因此仅将单幅样图用于本地有限目视核验，不批量下载、不做图砖缓存、不从栅格数字化线路。官方矢量图层仍须按前述流程申购。

## 在当前实验中的用法

1. OSM 快照留在规划输入之外；每轮候选结果冻结后，才读取它进行事后评分。
2. 结果标注为「与 OSM 参考线的比较」，不能写成工程真值或现场 5% 精度达标证明。
3. 若要做真正独立的站间验证，应改用独立核实的站侧接入点，并获取权威竣工中心线/塔位；若暂时无法取得，报告中必须明确说明。
4. 分发 GeoJSON 或衍生结果时保留 OSM 署名与 ODbL 声明。
