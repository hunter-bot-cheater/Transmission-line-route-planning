# 线路规划数据源复核（2026-10-27）

本次只核验与地形、灾害、土地利用和输电资产有关的官方公开资料。数据只有在取得文件并核验年份、坐标、精度与覆盖范围后才可进入规划器；历史线路仍只用于候选冻结后的盲评。

### 20 m DTM

政府资料开放平台现列有[2026 年版全台 20 m DTM](https://data.gov.tw/dataset/178729)，说明资料以 20 m 网格提供，且不同图幅的制作年度不一。内政部 DTM 服务说明 20 m 服务为开放资料，1 m 资料仅限机关内部使用。可作为下一轮地形敏感性比较，但要先确认各图幅的实测年份、垂直基准、NoData 和实际覆盖，不能只按文件名判定其精度高于现用 DEM。

我们成功读取了官方资源清单 CSV；直接访问清单列出的 TGOS ZIP 文件得到 403。因此当前没有合法下载并核验实际栅格文件，也没有改变现行规划数据。

### 灾害与暴露

农业部公开的[115 年土石流潜势溪流](https://data.gov.tw/dataset/176524)包含 Risk、TRes_Class、长度、集水区及岩性等属性；[土石流影响范围](https://data.gov.tw/dataset/176526)含影响住户数级距/数量；[94 处大规模崩塌潜势区](https://data.gov.tw/dataset/176527)及[其影响范围](https://data.gov.tw/dataset/176528)也提供风险和保全户信息。资料说明涵盖全台 1,753 条潜势溪流和 94 处潜势区。

当前服务器已经使用同批 115 年来源的 ARDSWC z10 MVT 图层；服务器 manifest 记录 880 个瓦片请求、无失败瓦片，所观察到的 1,753 条溪流及 94 处崩塌区要素 ID 均有覆盖。MVT 明确经过按 zoom 概化且边界裁切，现有规划器只把它作为软风险掩膜，不能用于断言原始调查边界。若将来取得 SHP，应先与现有 MVT 做同一版本/ID 的覆盖比对，再以 SHP 替换相同图层，避免重复加权。

公开平台的 SHP 下载链接在联网工具中超时；从本地服务器对同一农业部域名的请求遇到 DNS 解析超时，本机请求遇到 SSL 连接失败。因此这批 SHP 已列为可信候选源，但当前并未获取数据文件。

### 国土利用与输电资产

国土测绘图资服务云说明[免申请提供部分 WMS/WMTS/API](https://maps.nlsc.gov.tw/S09SOA/pro/intro.jsp)，而国土利用现况相关 WFS/API 有额外申请条件。在线瓦片可帮助检查空间上下文；离线成本栅格仍需明确授权、范围、更新日期和覆盖声明。公开目录检索未找到可直接下载的台电竣工线路与塔位/回路数据。后续应优先确认可授权的线路/回路 ID、站内出线端点与竣工线身份；未取得前继续使用现有线路做盲评分，不能把历史折线喂给规划器。

## 后续顺序

1. 先取得并验证真实站间任务 ID、两端线路侧接入点及线路/回路身份。
2. 通过官方支持的下载途径取得农业部 SHP 与 2026 版 20 m DTM，记录文件 SHA-256、CRS、年份、垂直基准、空间覆盖和授权。
3. 对 20 m DTM 与现用 DEM 做固定输入的 3 案例对照；先比较有效像元间距与高程/坡度统计，再比较冻结路线的后验误差，避免将名义分辨率误写成路线精度。
4. 对灾害 SHP 和现有 MVT 做逐 ID 差异与覆盖审计，再按 Risk/住户暴露设计单一、透明的软代价；潜势图层不直接作为硬禁区。
5. 每次只改变一个已核验的数据层，并保留独立站间样本，检验改进能否跨案例复现。
