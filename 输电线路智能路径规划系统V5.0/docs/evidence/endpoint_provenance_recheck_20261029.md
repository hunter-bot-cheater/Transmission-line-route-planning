# 线路评测端点来源复核

日期：2026-10-29

## 目的

复核既有台湾线路几何对比中的起终点是否来自独立于参考线路的站点资料。该检查只读取冻结清单、评分结果、台电公开站所目录和服务器实验记录；没有把参考线几何送入规划器，也没有重跑线路。

## 发现

- 服务器端点审计复核了 3 个用例的 6 条候选线。规划任务端点与评分参考线端点的最大配对差为 0.05–0.07 m；候选线首尾点与参考线端点也在同一范围内。审计报告将这些端点标为探索性代理点，且没有独立的线路侧接入点凭证。
- 该精度接近坐标取整精度，构成参考端点泄漏的强烈迹象，但仅凭几何吻合不能确定坐标具体由谁、何时取得。当前应将这些路线分数标为“端点来源未核实的探索性事后比较”，不能当作独立站间评测或真实线路误差。
- 服务器保存的台电超高压及一次变电所公开目录包含深美 E/S、冬山 E/S 名称和行政区等字段，但没有坐标列；目录说明也明确其不能证明测量接入点或塔位。该目录只能帮助识别站点，不能替代线路侧端点资料。
- NLSC 1:5000 图资说明包含高压线与铁塔图层，但公开产品说明尚未证明其属性可辨识具体回路、345kV 电压或塔号。因此即使取得图幅，仍须先检查实际属性，不能预先把它视为目标线路竣工真值。

## 评测边界

1. 规划输入继续排除历史线路几何；线路和塔位数据仅能在规划冻结后用于事后评分。
2. 在取得可追溯且独立的站端接入点前，报告必须单列起终点来源状态，并把端点偏差与内部走廊偏差分开。
3. OSM 线路对比仅用于探索性地图几何诊断；不能据此宣称台电竣工线误差达标，也不能用其分数调节规划权重。
4. 真实工程可行性仍未评估。当前塔位筛查参数、档距和塔址代理值不是已核实的设计规范。
