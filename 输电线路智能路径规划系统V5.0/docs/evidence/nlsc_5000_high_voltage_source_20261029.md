# NLSC 1:5000 高压线路与铁塔数据来源核验

日期：2026-10-29

## 结论

目前找到最有希望用于独立线路核验的官方高精度图资：内政部国土测绘中心 1:5000 数值地形图。官方 FAQ 明确列出公共事业网络中的“高压线塔及高压电线”，向量格式包括 SHP、DWG、DXF。它可用于规划冻结后的事后线路与塔位对比；线路和塔位不得作为本项目规划器输入。

当前没有取得或下载这组向量数据。指定图幅是否限制公开、图层属性是否能区分目标回路/电压/塔号，需要通过图资商城或实际图档进一步核实。不能把地图线直接当作已验证的竣工中心线。

## 可获取渠道

- [NLSC 1:5000 数值地形图 FAQ](https://www.nlsc.gov.tw/News_Toggle.aspx?_CSN=2033&n=1564&sms=9708)：说明图资格式和图层包含高压线塔、高压电线。
- [NLSC 图资费用与申请说明](https://www.nlsc.gov.tw/cp.aspx?n=1549)：非限制公开的 1:5000 像片基本图数值资料按图幅供应，首次非加值型为每幅 NT$150；限制公开图资需同意书。学术单位可依收费标准公文申请减征，具体金额尚未核实。
- [NLSC 图资服务云 WMS](https://wms.nlsc.gov.tw/wms?SERVICE=WMS&REQUEST=GetCapabilities)：当前 GetCapabilities 中有 `B5000`（1:5000 基本地形图）图层。该图层标记为 `queryable=0`，本次从 WMS 取得的是 PNG 渲染图，不能直接取得 SHP 几何或属性。
- [政府资料开放平台的高压电塔开放建议](https://data.gov.tw/suggests/17292)：检索到的是“敬请开放高压电塔位置资讯”的建议页，不是可下载的全国高压塔数据集。

## 排除的近似数据

台电在政府资料开放平台提供的[宜兰县电桿坐标](https://data.gov.tw/dataset/139319)和[花莲县电桿坐标](https://data.gov.tw/dataset/139320)是免费 CSV，字段为行政区、图号坐标、形式、桿号和 TWD97 坐标。本次只在内存中读取以核对数据类型：宜兰县 81,095 行、花莲县 118,380 行；形式均为水泥桿、钢桿、H 桿等配电桿类别，没有“塔”类别。它们不适合当作 345 kV 输电塔位或真实线路参考，且没有把文件留在本机或服务器。

## 下一步

1. 先按目标线路覆盖区确定 1:5000 图幅清单，再在 NLSC 商城核对这些图幅的公开限制、SHP 图层及总价；不进行付款或提交身份凭证操作。
2. 若图幅可购且费用可接受，再申请原始 SHP。取得后检查坐标系、来源/测制时间、塔位与线要素字段、目标线路归属及数据限制。
3. 只有在确认线路归属、年代与定位质量后，才将该资料作为独立测试参考；规划输入仍只含地形与非线路工程约束。
4. 若属性不足以分辨目标回路，继续寻找台电竣工/巡检塔位资料；当前只能将 NLSC 线图作为可追溯的地形图参考，不能宣称是竣工真值。

## 本次核验范围

仅检查公开目录、官方图资说明、WMS 能力文件及台电县市 CSV 的字段/类别；没有访问变电所内部系统、购买数据、登录商城、提交申请、在本机运行线路规划或改动服务器文件。
