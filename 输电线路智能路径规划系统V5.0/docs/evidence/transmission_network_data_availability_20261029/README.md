# 台湾输电线路规划可用电网数据审查（2026-10-29）

本次只核对台湾政府开放资料平台与台电公开目录，不下载数据、不改变服务器，也不把这些图层接入规划代价。

## 公开目录核查

| 数据 | 官方资料内容 | 是否能作为架空输电规划输入 |
|---|---|---|
| [台电电桿坐標及桿號（dataset 33305）](https://data.gov.tw/dataset/33305) | 全台电杆坐标与杆号，字段列出县市、行政区、乡里、形式及 TWD97 XY，目录更新频率为每月。 | 目录没有声明电压等级、输电回路、塔型类别或站端接入点；在核实字段和样本前，不能把全台电杆直接当成 161/345 kV 输电塔。 |
| [台电变电所主变容量及负载（dataset 16960）](https://data.gov.tw/dataset/16960) | 超高压、一次及二次变电所名称、所在地、供电范围和容量/负载。 | 目录未提供精确坐标、出线间隔/端子或线路拓扑，不能据此生成经核验的线路起终点。 |

## 对规划器的处理决定

目前不下载上述电杆和地方管线图层到服务器，也不把它们作为高压塔位、禁行区、线路中心线或路线先验。数据分类缺失可能让规划器把配电杆、地下管线和架空高压输电混为一谈，得出的“靠近线路”或“避开设施”结论会误导用户。

目前的台湾 DEM、居民暴露、灾害风险和经核验的陆域边界可以支撑走廊初筛；它们不能单独恢复真实输电线路走向，也不能完成塔位和导线工程校核。现有真实规划页面因此将无名录的地图点选任务标记为探索性。

## 要让结果升级为可核验站间候选，所需资料

优先向项目合作单位或台电申请并核验：

1. 站点编号、正式名称和线路侧接入点坐标，含坐标系、测量来源、基准和可追溯凭证。
2. 输电塔/杆的编号、坐标、回路编号、电压等级、塔型、横担/挂点高度及线路连接关系。
3. 导线型号、档距、弧垂/张力参数、最低净空及地形/交叉设施的校核规则。
4. 线路走廊权属、既有通道和已核准的法定/项目限制区。
5. 用于独立事后评估的竣工中心线和施工变更记录；这些评估几何不得进入候选生成阶段。

在拿到授权且经过坐标、覆盖和字段验证之前，不能把上述缺口用地名地理编码、普通电杆或 OSM 线路猜测补成“已核验”信息。
