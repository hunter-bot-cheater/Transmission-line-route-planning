# 塔基平台灾害暴露诊断

## 变更

实验性塔位路线现在会逐层报告内部塔位圆形平台与土石流影响范围、大规模崩塌潜势区及影响范围栅格的已知相交。诊断复用塔位筛查的同一像元足迹，只写入路线指标，不改变搜索代价、路线几何或候选选择。

没有相交只有在该灾害层覆盖状态为 `complete`、平台半径已配置且整个足迹位于 DEM 栅格内时，才报告 `complete_coverage_no_overlap`。其余零相交情况均为未知；未配置平台半径时仅检查中心像元，且明确标记平台足迹尚未评估。站端不纳入内部塔位统计。
