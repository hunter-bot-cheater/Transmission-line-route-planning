# 站点间线路规划设计说明

## 1. 规划对象调整

输电线路规划对象应是固定变电站或明确的线路接入点之间的线路任务，而不是没有业务身份的两个经纬度。本项目现有 `real_cases.csv` 的端点取自测试线路折线首末点；它们只适合复现实验和事后评估，不能当作已核实的变电站或接入点。工作区目前没有可核验的站点名录，因此只提供输入模板，不填造站名和坐标。

新增两个输入表：

| 文件 | 必需字段 | 用途 |
| --- | --- | --- |
| `stations.csv` | `station_id,name,lat,lon,coordinate_crs` | 站点台账；`lat/lon` 应是线路进出线接入点坐标，`coordinate_crs` 必须填写 `EPSG:4326`。程序不转换其他坐标系，也无法证明声明与原始坐标一致。可补 `station_type,voltage_kv,source,verified`；有核验资料时还可填 `ground_elevation_m,ground_elevation_source,vertical_datum`。 |
| `route_tasks.csv` | `route_id,from_station_id,to_station_id` | 明确每条规划任务所连接的两个站点；可补线路 `voltage_kv`。 |

模板位于 `examples/stations_template.csv` 和 `examples/route_tasks_template.csv`。起终站必须存在于站点表中；重复 ID、未知站点、无效坐标和两端电压等级不一致且未填写线路电压的任务会被拒绝。搜索会将接入点映射到其所在 DEM 像元；最终路线首尾保留 CSV 中的精确坐标，并记录该点到栅格中心的距离。程序不会把站点移到附近的可通行像元；若接入点所在像元是 DEM 空值、建筑或配置禁区，任务会报错，应先核对真实站端接入坐标或数据。

变电站选址与固定站点之间的线路走廊优化是两个不同问题。本次实现固定站点之间的走廊筛查，不决定新建站址、不自动生成进出线间隔坐标，也不选择站址。

## 2. 规划因素与实现

事后线路相似度评测中，`--real-shp` 与 `--real-dir` 匹配到的每个参考文件均须恰含一个 `LineString` 要素。多个回路或多个资产必须先按资产 ID 分开评测；同一线路分段时，应先合并成单一线路要素。包含多要素或 `MultiLineString` 的文件会标记为无效参考，不计算相似度，以免邻近无关回路抬高覆盖分数。

### 2.1 硬约束

- DEM 空值像元不可通行。
- 已映射的 OSM 建筑轮廓作为硬障碍；`--building-clearance-m` 可额外设置栅格避让距离。默认 0 米只屏蔽已映射建筑足迹，不表示满足任何法定净距。
- `--max-surface-slope-deg`、`--max-terrain-elevation-m`、`--max-ground-grade` 是可选筛查阈值，默认均不设置。配置这些值不会使其自动成为工程标准限值。

参考线几何不能解除以上硬约束。未配置的环境敏感区不会被默认判定为可建设。

可选参数 `--constraint-geojson` 接收用户整理的 WGS84 GeoJSON 多边形约束图层。每个 Polygon/MultiPolygon 要素必须在 `properties` 中填写 `mode`（`hard` 或 `soft`）和 `source`；软约束还需填写非负 `weight`，可选填写 `category`。硬约束覆盖到的栅格像元会禁止通行，软约束权重会累加到路线软代价；输出按来源和模式记录要素数、覆盖像元数及实际受影响像元数。若某来源的 `covered_cell_count` 为 0，表示该来源的几何没有栅格化到当前 DEM 窗口；这不代表数据集本身为空。点或线要素应先依据适用规则生成带缓冲的多边形后再导入。系统不会替用户推断保护范围、居民点避让距离或软权重；输入图层已加载也不代表覆盖完整，需由项目方核对数据日期、来源和区域范围。

### 2.2 软代价

当前默认代价面可解释并可复算：

```text
terrain_cost = 0.75 * clip(surface_slope / 45 degrees, 0, 1)^1.5
             + 0.25 * clip(roughness_27 / 100 m, 0, 1)
             + ridge_penalty_weight * clip(max(TPI_300, 0) / 200 m, 0, 1)
building_proxy = clip(smoothed_mapped_building_cell_fraction, 0, 1)
residential_proxy = OSM_landuse_residential_mask
builtup_proxy = indicator(OSM_landuse_code == 4)  # residential/retail/commercial/urban
settlement_proxy = max(building_proxy, residential_proxy, builtup_proxy)
landcover_proxy = indicator(OSM_landuse_code in {1, 7})
route_cost = terrain_cost + settlement_weight * settlement_proxy
             + landcover_penalty_weight * landcover_proxy
             + official_hazard_weight * max(debris_flow_impact,
                                             landslide_potential,
                                             landslide_impact)
             + population_weight * population_proxy  # optional; default 0
```

可选人口层要求同时提供 `--population-raster` 与正的 `--population-weight`。程序把源栅格“每像元人数”按 WGS84 椭球像元面积换算为 people/km²，再按固定尺度 `clip(log1p(density) / log1p(10000), 0, 1)` 生成软代理；`10000 people/km²` 是归一化尺度，不是规划标准。NoData 保持为未知且路线覆盖率单独记录；默认 `--population-nodata-policy maximum` 在搜索时给未知像元最大归一化惩罚，避免未知区成为低成本通道；`median` 可将未知像元填为 DEM 有效区域内已知人口代价的中位数，`zero` 可作零代价填补敏感性场景。后两者是缺失假设敏感性分析，不表示真实人口，必须与路线未知像元数一起解释。当前 WorldPop 数据是约 100 米的模型估算，细分重采样不增加其空间精度；该层不等于逐户人口、敏感目标名录或官方最小统计区统计。数据许可、年份、DOI 和出处会从 GeoTIFF 标签及匹配的 STAC 侧车写入结果。默认权重为 0，不参与规划。

默认从 `data/official_sources/ardswc_115_mvt_z10_20261023/` 读取农业部 115 年土石流影响范围、大规模崩塌潜势区和影响范围的 MVT 瓦片；默认 `official_hazard_weight=1.0`。三个二值层取并集后只加一次代价，结果另行保留各层的线路接触比例，避免重叠区域重复累加。它们均为软风险筛查，绝不直接变成硬禁区。目录清单、SHA-256、瓦片读取/空瓦片/缺片状态、数据日期、z10 与请求范围覆盖度会写入结果；未知覆盖会使规划状态标为数据不完整。MVT 经过比例尺简化并裁切于瓦片边界，未保留原始属性，不能区分风险等级或受影响住户，也不能替代原始官方 SHP 的风险与暴露字段。该联合权重是项目筛查设定，不代表风险等级换算或工程规范。

`TPI_300` 表示像元高程相对约 300 米邻域平均高程的差值。默认 `ridge_penalty_weight=0.10` 仅给相对高脊增加弱软代价，负 TPI（相对低地）不受奖励；可通过 `--ridge-penalty-weight` 调整。TPI 是地形位置指标，不代表滑坡或风暴风险，也不保证既有线路贴合。若缺少可计算 TPI 的依赖，其图层为零，路线退化为其他已启用代价项。

土地利用码 1（林地、木本灌丛等）和 7（湿地、沼泽等）可通过 `landcover_penalty_weight` 加入低权重环境扰动与植被清理筛查，默认值为 0（关闭）。固定权重 0.10 的 12 线路消融使 F1@100m 均值从 3.29% 降至 3.07%，故不启用为默认项。OSM 标注不完整，类别也不代表法定保护区或经核验的施工禁区；缺失标注只是不增加该项代价，不能解释为确认无环境限制。正式选线应接入适用且有来源、日期记录的官方保护区与地质灾害约束。

建筑代理由 OSM 建筑栅格经过约 500 米尺度的平滑得到，表示被建筑轮廓触及的像元比例，不是建筑实际占地率或人口密度；密度计算的建筑查询范围和中间栅格在规划窗口外各扩展约 2 公里，平滑后再裁回，以减少窗口边缘效应。启用建筑净距筛查时，查询范围扩展至 5 公里，以覆盖距离栅格的最大计算半径。不使用每个任务窗口自己的 P99 作缩放，避免同一值因窗口内极值变化而改变代价。住宅覆盖面和用地代码 4（住宅、零售、商业或都市用地）也参与建成区代理，三个信号取最大值以减少重叠区域重复计价。它们均不等于居民人口、完整住宅用途或敏感目标清单。默认 `settlement_weight=2.0` 是方案筛查参数，允许用 `--settlement-weight` 调整。默认不加载 CostUNet；本轮评测也未启用它。若在其他运行中显式设置 `--use-costunet`，模型训练线路来源仍须先行核验。

A* 每次移动边的基础费用为起点格与终点格代价的平均值乘以米制移动距离；这等于按当前北向上 WGS84 栅格的局部行列米制尺度，把格内常值代价沿两个像元中心之间的路径精确积分。它不是椭球测地线积分，也不支持旋转或非正交仿射网格。移动还计算相邻 DEM 像元的地面高差率，其软惩罚为 `grade_penalty_weight * min(local_ground_grade / 0.30, 1)`；`--max-ground-grade` 可选地将超限边设为不可通行。像元尺度下的地面高差只用于路线筛查，不代表导线纵断面或塔位坡度。导出前先尝试起终点直连捷径：只有直线的 supercover 硬约束检查、配置的地面坡度限制及同一连续目标代价检查全部通过，且代价不高于原路线时才采用；否则继续使用原平滑候选，并在硬约束或代价检查不通过时保留原搜索线。基础栅格代价按边界穿越长度积分，高差和转弯项仍为采样估计；这能防止后处理使筛查目标变差，但不把像元路线变成塔位/导线工程模型。

为保证同一无向站间任务交换起终点时仍返回同一条栅格路径，搜索内部按栅格序固定端点方向，并在相同优先级时优先扩展启发值较小的节点，输出时再恢复用户指定方向。该规则不读取参考线，也不改变代价面。历史 12 条线路曾用于开发诊断，现冻结为事后对照集；旧版 F1@100m 等数字留作历史记录，不再作为本轮规划目标，也不用于调整权重或选择最终候选。每轮主要检查输入图层覆盖、硬约束复核、风险暴露、路径代价组成、搜索时间与不同权重下的方案稳定性。

默认启发权重 `1.0` 的 A* 对当前离散代价面求最优路线；显式设置大于 `1.0` 的权重才启用加权搜索。加权搜索会在发现更低代价时重新打开节点，并跳过过期队列项；在输入边代价非负、基础启发式可采纳时，针对相同的实际搜索端点，未平滑搜索路径的目标代价不超过权重乘以同图最优代价。当前函数可能将落在禁行像元的端点吸附到附近有效像元，且不强制校验所有代价栅格为非负；不满足这些前提时不承诺该界。该界也不覆盖平滑、端点恢复或后续路线处理。可选 `--turn-penalty-weight` 启用方向状态 A*，对连续栅格边的转向角添加非负成本；其角度根据实际像元米制宽高计算，权重 `0` 保持基础搜索目标。该模式为方案筛查实验，不是塔位转角或线路设计规范；8 方向状态数组会显著增加内存，高分辨率任务会在启用时显示估算。

### 2.2.1 实验性候选塔位图

`--experimental-tower-graph` 在同一 DEM 代价面和硬通行掩膜上建立稀疏候选塔位图：起终端固定，允许设塔的可通行像元作为候选节点，只有水平档距落在调用方提供的 `--tower-min-span-m` 与 `--tower-max-span-m` 范围内且跨距不穿越硬障碍时才连边。`--tower-candidate-stride` 控制栅格抽样步长，默认 2；步长会改变可达性，粗采样可能漏掉窄走廊或可行塔位。此试验没有已校准的塔位施工成本，当前塔位节点成本为零；路线目标只含跨距栅格代价和可选转角项。

若同时提供 `--tower-attachment-height-m`、`--tower-max-midspan-sag-m`、`--tower-min-clearance-m`，程序会作固定挂点和抛物线弧垂的简化 DEM 净空筛查；缺任一参数即拒绝配置。没有导线型号、温度、风冰荷载、塔型、交叉物高度和电压等级规则，因此“通过”只表示通过该简化筛查，不构成导线净空认证。现阶段塔位图只作为对照候选写入 `paths.json`/路线比较文件，不参与默认最终选路。

### 2.2.2 实验性采样 Pareto 路线候选

`--experimental-sampled-pareto` 对同一地形/约束代价栅格运行有限组环境代价与距离权重的 A*，按基础代价、地面高差惩罚、转弯惩罚和路径长度筛出这些采样路线中的非支配子集。它不是整个可行路径空间的完整 Pareto 前沿。候选经过与常规路线相同的平滑、端点恢复、坡度与硬约束复核；启用该参数会输出 `sampled_pareto_freeze.json`、`sampled_pareto_candidates.json`、各候选 GeoJSON/SHP 和候选对比图。冻结清单在加载参考线路之前写入，并记录后处理候选路径 SHA-256；真实线只在最终路线选择后用于事后评分。

目标向量描述平滑前的搜索栅格路径；后处理几何的代价积分、线路长度、硬约束结果和参考线相似度另行记录。有限权重采样可能漏掉非凸或未采到的路线。该接口只扩展筛查候选，不参与 `_select_final_route` 的正式路线优先规则，也没有杆塔档距、导线净空、跨越许可或经核验站端等工程设计输入，因此不能据此称为工程可行方案。

默认规划运行基础 A*，不启动 VIN/PPO。只有显式设置 `--astar-heuristic-weight` 大于 `1.0` 才运行加权近似搜索；AI 方法仅在显式指定 `--include-ai-diagnostics` 后作为对照运行，永不作为最终路线候选。参考线路只在路线生成和选择完成后读取用于评分。

### 开源实现参考

本规划器采用“栅格通行代价 + 米制移动距离”的最小代价搜索，可与 [GRASS GIS `r.cost`](https://grass.osgeo.org/grass-stable/manuals/r.cost.html) 的累计栅格代价作同目标对照；其 8 邻域之外的 knight-move 邻接可用于独立评估栅格方向偏差，但必须单独验证是否会跨越窄障碍。GRASS [`r.walk`](https://grass.osgeo.org/grass-stable/manuals/r.walk.html) 的核心是 Naismith/Langmuir 行走时间，不适合作为输电线路工程成本模型。[PowerPlanner](https://github.com/NinaWie/PowerPlanner) 把候选塔位建成图节点，用允许档距连边并分别计入塔位、跨越和转角成本；这是从像元线转向塔位线最直接的开源算法参照，但它是研究代码，不能代替本地规范和导线校核。[PYORPS](https://github.com/marhofmann/pyorps) 的主要场景仍是地下电缆，0.4.0 README 列有 corridor graphs 与 tower fields，状态需按 release-status 页面逐项核实。[2019 年架空线规划研究](https://www.sciencedirect.com/science/article/pii/S037877961930272X)提出分阶段的走廊搜索、转角候选点优化和纵断面塔位布置。本项目现已加入实验性稀疏塔位图，但尚未有经验证的候选塔位、塔位成本和电气/机械参数；后续应先补充电压等级、导线、适用规范档距、风偏/弧垂净空与许可约束，并与独立站端接入点配套，不能据当前候选路线声称工程可建或比既有线路更贴合。

### 2.3 站间高差与纵断面

每条输出路线会将线段加密到不超过一个 DEM 像元后采样，并记录两端 DEM 高程、`endpoint_dem_elevation_delta_m`、沿线最低/最高点、累计上升/下降、最大采样地面坡度和高程采样覆盖率；同时写出加密后的 `elevation_profile.csv`。超出 DEM 范围的样本记为无效值，不会用边缘高程替代。站点表可附带经核验的地面高程及其来源、垂直基准；只有两端测量均齐全、来源信息齐全且基准一致时，才计算 `station_ground_elevation_delta_m`。该测量差与 DEM 端点差分开报告，不覆盖 DEM，也不自动作为选路阈值。同一站间任务的端点高差本身不能区分候选路线优劣；更有用的是沿线脊谷、累计升降和局部坡度，但这些也不能单独判定可建性。当前 `voltage_kv` 作为任务元数据记录，不会自动套用电压等级对应的设计约束。

## 3. 数据现状与限制

- 当前工作区外部 DEM 为 EPSG:4326、约 35 米网格，覆盖现有 12 条测试线的 24 个端点且端点采样均非 NoData；但文件元数据未记录可核实的数据来源、版本或垂直基准，且该大文件不在 Git 中。默认 `--max-side=4096` 可保留这 12 个样例窗口的原始栅格；更大的输入仍会降采样，程序会在日志标出实际像元和倍率。已找到官方最新 2026 版公开全国 20 米 DTM，但其 CSV 目录资源显示为 DSM，网格间距也不等于高程精度；类型、图幅年份、坐标系与高程基准需逐幅校验后才能替换当前 DEM。高分辨率数据源和申请限制见 `公开数据与获取流程.md`。
- 当前 CLI 的站点坐标、OSM 几何与栅格索引均按 WGS84 经纬度组织；会拒绝非 EPSG:4326 或缺少 CRS 的 Rasterio DEM。其他投影 DEM 需先重投影后再运行。
- 台湾区域 OSM 缓存包含建筑轮廓，可用于初筛；覆盖不完整、用途属性不足，结果需人工核对。
- 结果元数据会标示各 OSM 缓存缺失、无要素、未覆盖请求范围或存在要素的状态。若范围外非有限坐标要素被跳过，覆盖状态改标为 `partial` 并记录跳过数量，因为缺失坐标无法证明其影响范围。缓存中观测到的要素范围不能证明 OSM 完整覆盖；`empty_in_bbox` 也不能解释为“确认无人居住”。
- 当前 `taiwan_protected.pkl` 的几何实际落在中国大陆，不用于台湾线路规划。项目新增了从农业部自然保护区和环境部饮用水保护区官方数据生成 WGS84 约束面的脚本，但原始数据未随代码仓库分发，规划流程也不会自动加载。下载方式和更新日期见 `公开数据与获取流程.md`；在生成并核验该图层前，不得据规划输出声称已避让台湾保护区、饮用水源保护区或生态保护红线。
- WorldPop 100 米模型人口栅格仅可选软成本，默认关闭；官方最小统计区边界及配套人口资料当前未进入规划流程。住宅名册、学校医院等敏感目标台账、自动加载的保护区边界、道路施工便道/通行权、交叉跨越许可、真实候选塔位及导线工程净空计算仍缺失。可获得的数据和最新获取状态见 `公开数据与获取流程.md`。
- `--max-surface-slope-deg` 是 DEM 地表坡度筛选；`--max-ground-grade` 是相邻栅格地面高差筛选。两者均不是架空输电线路设计规范中的坡度限值。
- 路线视觉相似度 v4 将规划线和参考线投影到本地等距米制坐标，按约 20 米弧长间距采样；每个样点按其代表的线路弧长加权，并先在源坐标平面合并参考几何中的重复/重叠部分，避免重复要素对同一空间重复加权。双向均值、分位数和 100/500/1000/5000 米长度覆盖率按弧长加权；F1 是两个方向覆盖率的调和平均，对称均值则是两个方向均值的算术平均。它另报告参考线落在规划栅格窗口内的长度比例、采样最大偏移、独立长度差和缓冲区 IoU；当参考几何合并为一条开放线时，另报告端点偏差和固定 256 点离散 Fréchet 近似。窗口覆盖比例仅表示参考线几何在规划栅格窗口内的长度占比；距离和覆盖评分仍按完整参考线计算，不会自动裁切窗口外部分。100/1000 米 IoU 是各自对中心线外扩对应半径后的面积重叠，不等同于 100/1000 米中心线距离覆盖；固定 256 点 Fréchet 可能漏掉采样间隔内的局部偏差，不作为主误差判据。距离分位和覆盖仍是约 20 米抽样估计，采样最大值也是近似诊断量。所有指标只衡量相对所提供参考线的几何差异，不代表参考线自身精度或工程可建性。若需比较并行回路或重复资产，应按资产分别评估，不能把重复几何作为额外线路长度。

## 4. 运行方式

从软件包目录运行：

```powershell
python -m transmission_path_planner `
  --dem ./data/taiwan_dem_35m.tif `
  --osm-cache-dir ./data/downloaded `
  --stations-csv ./examples/stations.csv `
  --route-tasks-csv ./examples/route_tasks.csv `
  --constraint-geojson ./data/verified_constraints.geojson `
  --out-dir ./results/station_routes `
  --no-ppp
```

复制模板并填入经核实的站端接入点后再运行。若输入站点地面高程，应同时提供测量来源和垂直基准；缺少这些字段时会保留原始数值，但不计算两端实测高差。站点表中的高程不能代替 DEM 采样。自定义图层格式和限制见上文。每条任务的 `paths.json` 保存各方法生成的非空路径；有可行最终路线时另输出路线 GeoJSON、纵断面 CSV 和地图，无路线时路径集合可能为空。批次根目录 `comparison_metrics.json/.csv` 仅汇总已记录任务，规划中失败的任务见 `run_summary.json` 的 `failed_cases`。根目录兼容文件 `metrics.json` 仅可能由首个到达兼容输出环节的任务写入，且该任务必须含 VIN 指标；后续任务不补位。无可行路线时任务记入 `no_route_cases`，不会伪报批次完整。逐任务参考线无效或无法读取时会记录评测状态并继续导出规划结果；指标记录站点 ID/名称/电压/数据来源与核验状态、实测高程可比状态、启用的筛查权重，以及未覆盖的工程校核。`planning_status` 只会标记为筛查候选、数据不完整的筛查候选或无硬约束合规路线；`hard_constraint_status` 与 `hard_violations` 描述最终导出几何的复核结果。建筑/土地利用代理图层缺失或未观测到要素时，结果会标记 `osm_data_quality=incomplete_osm_proxies` 并列出 `missing_osm_screening_layers`，不能按“无居民点”解释。

## 5. 工程规范边界

生态环境部 HJ 1113-2020 的选址选线条款要求考虑生态保护红线、自然保护区、水源保护区、居住及其他功能区，并要求架空线路经过电磁环境敏感目标时采取避让或增加导线对地高度等措施；HJ 24-2020 要求记录敏感目标的位置关系、建筑高度及导线对地高度等信息。因此，单一建筑密度栅格不能替代环境敏感目标调查。

国家能源局公开的电力建设标准名录按电压等级列出了不同架空线路设计标准。国家能源局关于导线风偏的答复还指出，实际风偏计算涉及档距、导线型号、设计风区、杆塔高度和绝缘子串长等参数，需要逐档计算。本软件输出是早期方案筛查，不是线路工程设计或合规审查结论。
