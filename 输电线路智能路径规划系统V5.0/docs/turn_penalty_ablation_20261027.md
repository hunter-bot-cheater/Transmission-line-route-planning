# A* 转弯权重三案例对比记录 2026-10-27

## 结论

完成 3 个固定端点案例、4 个新增权重（0.1、0.25、0.5、1.0）的 12 次服务器 CPU 规划，并与每例权重为 0 的冻结基线组成 15 条候选。全部新增运行成功。真实线路仅在所有候选冻结后用于事后评分。

15 条候选的双向较差方向 P95 最小 3.026 km、中位数 5.243 km、最大 9.095 km；100 m 对称 F1 范围为 1.401%–2.222%，没有候选达到 P95≤100 m。转弯权重没有消除历史走廊与规划走廊的公里级偏移。

## 方法与解释边界

规划候选生成时未读取历史线路几何。候选坐标冻结并校验哈希后，才计算双向较差方向 P95 与 100 m 对称 F1。P95 为规划线到参考线、参考线到规划线两个方向 P95 中较大者；F1 为两个方向容差覆盖率的调和平均。

本轮命令行参数 turn_penalty_weight 同时传入方向状态 A* 搜索和约束感知平滑器。因此本实验只识别“搜索与后处理的联合端到端变化”，不能归因于 A* 搜索项单独作用。为避免口径误导，本报告不把未投影的顶点角度数作为平滑性结果，也不混合路线搜索计时与服务器整次 CLI 耗时。

样本仅有 3 个固定端点案例，且端点来自历史线路样本，尚未全部核验为变电站线路侧接入点。0 个硬约束违规仅表示已配置检查层中未检测到冲突，不构成工程可行性证明。详情见冻结计划、候选哈希清单、评分 CSV 和服务器运行摘要。
