# 官方规划数据源核查（2026-10-24）

本核查区分“官方目录中有资源”和“已下载并验证的本地文件”。只有后者才可进入规划成本或硬约束；历史线路几何仍只用于规划后的评估。

## 当前本地数据状态

- 规划复测使用 35 米 DEM：`data/taiwan_dem_35m_georef_fixed.tif`；该文件的原始来源、垂直基准和质量报告仍待核验。
- OSM 建筑/用地缓存位于工作区外的 `D:\大创\V5_final\data\downloaded`；本轮规划曾读取其中缓存，但图层覆盖完整性未验证。
- 项目目录中没有最小统计区边界、统计区人口或 20 米 DTM 文件；已找到用于事后评估的历史线路 Shapefile。当前规划仍使用 35 米 DEM、OSM 缓存和官方灾害 MVT 缓存。官方资源请求未能在本机保存上述边界、人口和高分辨率地形文件。
- 软件包内有农业部土石流/大规模崩塌 MVT 缓存，复测命令采用 CLI 默认目录；它是风险软代价，不代表法定禁建边界。

## 下一轮接入顺序

1. 优先获得带 CRS、更新时间、覆盖说明的 20 米 DTM 文件，并检查所选 TW58/TW173 规划窗口的完整覆盖，再用冻结参数复跑；不因参考线分数选 DEM 或权重。
2. 取得县市最小统计区 SHP 及同年度人口表，核验统计代码连接率、分带、几何有效性和人口单位后，先作为暴露软代价和评估指标。
3. 申请台电脱敏输电塔/站端/线路拓扑样本。没有电压等级、塔型、导线、档距和净空依据前，候选塔图仍是算法实验，不接入生产规划器。
4. 每个接入图层保存原始 URL、下载时间、许可、SHA-256、CRS、范围、字段和处理命令；不得把目录元数据或网页检索结果写成“数据已下载”。
