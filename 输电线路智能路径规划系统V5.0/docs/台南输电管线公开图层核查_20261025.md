# 台南输电管线公开图层核查（2026-10-25）

## 结论

已从台南市政府开放平台下载并解析全市道路范围的输电系统管线 KML。文件含有详细线几何，适合保留为**局部规划后参考图层**；但它没有站点要素、线路电压或可确认的站间回路配对，且市府注明图资仅供参考、暂无更新资料。因此它不能作为独立站间盲测真值、线路规划先验或工程可行性证明。

## 来源和复现

## 本次数据检查

- KML 可完整解析，包含 1,298 个 `LineString` 要素、190,240 个坐标顶点和 1,298 个唯一识别码；没有缺失线几何或起终点编号。坐标范围约为 120.0747–120.4886°E、22.9293–23.4959°N。
- 几何测地长度合计约 267.351 km，`管线长度`属性合计约 262.325 km；要素几何长度中位数约 230 m，最长约 726 m。每个要素更像局部管线段，不是完整的站间线路走廊。
- `timePosition` 范围为 1986-10-01 至 2019-12-17。门户资源元数据更新时间较新不能证明要素几何已同步现况；现场状态和资料更新日期仍需管线单位确认。
- 属性包含起终点编号、管理单位、管道编号、埋设深度、涵管条数、材料、管线长度及状态代码；没有线路电压、站点坐标、输电回路资产 ID、塔位/档距或导线净空字段。所有 1,298 个要素 `使用状态` 原始代码均为 `0`，但没有状态码字典，不能自行解释成现役或停用。
- 依起终点编号构图得到 291 个节点和 23 个连通分量；其中 172 组端点对重复出现，共有 906 条额外重复边。缺少代码字典和回路配对时，这种编号图不能直接当作电气拓扑或站间线路网络。

## 对规划评测的用途

由于图层没有变电站/线路侧接入点，本轮不能据此生成真实站间评测任务。以后若项目方另行提供独立核验的两端坐标，可先冻结只使用地形和约束生成的规划结果，再将此图层用于台南市范围的局部几何暴露诊断；评分时不得让管线 KML 参与代价、候选选路或权重选择。该有限诊断仍不能代替台电确认的线路资产、电压、站端接入位置、逐档塔位及工程净空校核。
