# 开源电力线路规划方案调研（2026-10-24）

## 结论

没有找到一个开源仓库能在缺少输电工程和许可数据时，单凭地形自动复刻既有高压线路。更换 A*、Dijkstra 或启发式搜索器，能改变搜索速度和离散路径，不会补出目标函数中不存在的征地、走廊审批、跨越、塔型、档距或净空信息。当前不使用历史线路几何生成路线或选参数的边界下，也不能用历史线反推成本权重。

## 对本项目的决策

1. 保留规则 A* 作为当前单目标基线；先检验成本层、约束和数据质量，不把换搜索器当作精度提升。
2. 下一阶段可并列输出多目标候选走廊，并报告长度、地形暴露、人口/风险暴露、路线分离度和配置约束状态。只在相应图层通过 CRS、覆盖率、年份和字段 QA 后纳入目标。
3. 候选塔位图路由只能在取得真实站端点、塔位许可、线路电压、塔型、导线/地线、档距、风偏/弧垂与净空标准后转成工程可行性筛查。
4. 历史线路 SHP 保持锁箱，仅在候选和参数冻结后计算空间偏差；不得根据这些得分反复改参数。固定历史端点的实验也不等于独立站端验证。

## 来源与许可备注

仓库代码许可证不自动覆盖仓库中的案例数据；下载或复用前需分别核对代码、数据和论文附件的许可。上述工具多面向地下电缆或区域级早期选线，文献中的案例成绩不代表本项目台湾高压线路的效果。
