# 台北输电系统公开图层核查（2026-10-25）

## 结论

台北市开放平台提供输电系统管线 XML 和场站 XML，可作为**仅在规划完成后使用的有限区域参考图层**。它不是已认证的输电走廊真值，也不能提供合格的独立站间规划端点。本轮只审计数据结构和几何，不将其输入规划器、代价面、路线选择或调参。

## 来源和复现

- [台北市公共管线图资_输电系统管线](https://data.gov.tw/dataset/156861)：市府说明资料仅供参考、确切图资应洽管线机构；字段包含几何、起终点编号、管理单位、设置日期和使用状态。台北市资料页当前列出的 XML 文件为 1.34 MB，资源更新于 2026-02-23。
- [台北市公共管线图资_输电系统场站](https://data.gov.tw/dataset/156863)：字段含几何、识别码、管理单位、场站名称和状态；同样注明仅供参考。
- 原始 XML 已保存在被 `.gitignore` 排除的 `data/official_sources/reference_only/taipei_transmission_sites_20261025/`：`taipei_transmission_lines.xml` 与 `taipei_transmission_sites.xml`。公开下载地址分别为 `https://data.taipei/api/frontstage/tpeod/dataset/resource.download?rid=e02cc7b9-1918-4f49-9441-3de5e669c868` 和 `https://data.taipei/api/frontstage/tpeod/dataset/resource.download?rid=6b62553d-74c7-4e01-8736-6111afab4052`。
- 数据门户标示政府资料开放授权第 1 版；下载时间为 2026-10-25 UTC。原始档 SHA-256：线路 `91c79542a7752e74982432753c8a06a8d53082cb05f3a3665997d63ba1f0b2db`；场站 `eca8afaef3e94455f2c70cce334d02160c62bb82e581f5a72d106176295f5f4f`。
- 可复核统计：

```powershell
python tools/audit_taipei_transmission_reference.py `
  data/official_sources/reference_only/taipei_transmission_sites_20261025/taipei_transmission_lines.xml `
  data/official_sources/reference_only/taipei_transmission_sites_20261025/taipei_transmission_sites.xml
```

审计脚本只读 XML，并确认其几何 CRS 为 EPSG:3826 后才计算平面距离。

## 本次数据检查

- 管线 XML 有 993 个要素和 993 个不同识别码；其中 883 个同时含起点编号和终点编号，108 个缺起点编号、107 个缺终点编号。要素线几何长度合计约 160.971 km，`管线长度` 属性合计约 157.648 km，两种长度口径相差约 3.323 km；不能将属性长度或几何直接视为已测竣工走廊精度。
- 唯一端点编号共 259 个；场站 XML 只有 5 个点，场站识别码与管线起终点编号没有直接匹配。5 个点中 3 个与管线几何重合，另 2 个到最近管线几何约 408 m 和 469 m。场站名称中有线路名称/桩号，不能据此断言这些点是经过核验的变电站线路侧接入点。
- 图层坐标范围约为 EPSG:3826 `296841–312979 E, 2763229–2782203 N`，是台北市区的局部图层，不代表全台输电系统。数据字典未提供电压等级、线路资产配对、状态代码释义、塔位类型或档距/净空参数。
- 市府页面的“仅供参考”说明、起终编号缺失以及站点—线路关系未连接，限制了其作为真值的资格。可用于未来规划结果冻结后的局部几何诊断；不能当硬约束、规划先验、正式工程验收或独立站间盲测样本。

## 其他官方来源核查

- 台电[电杆坐标及桿号](https://data.gov.tw/dataset/33305)提供全台坐标，但公开字段没有输电电压、线路资产 ID 或塔位类别；普通配电电杆不能当输电塔位真值。
- 台电[超高压及一次变电所容量负载](https://data.gov.tw/dataset/16874)及[二次变电所容量负载](https://data.gov.tw/dataset/16960)有站名、所在地文字、供电范围和容量，没有可用几何坐标或线路侧接入点。
- 台南[输电系统管线](https://data.gov.tw/dataset/122514)公开 KML 目录，覆盖全市道路范围，但平台注明仅供参考、暂无更新资料，详细资料须洽管线单位。本轮从当前执行环境尝试下载 KML 时连接超时/未传输任何字节，未把它视为已取得或已校验数据。
- 水利署[水库集水区内侧 0.5 公里敏感区](https://data.gov.tw/dataset/129475)是可考虑的环境暴露图层：平台列出 SHP/KML 资源、政府资料开放授权第 1 版，资源清单记载建置日期 2023-05-05、元数据更新于 2026-10-16。当前环境连接其 gic.wra.gov.tw 原始下载端点失败，因此几何、CRS、覆盖和时效均尚未实测；即使取得，也只先做软性暴露筛查，不能把缓冲区直接设为禁建区。

## 后续最有价值的验证

申请一份脱敏的台电输电线路样本，至少包含现役线路资产 ID、电压等级、两端变电站及线路侧接入点坐标，并附数据日期与核验责任方；有条件时再提供塔位、逐档参数和许可/交叉跨越约束。把参考几何封存到规划运行之后才参与评分。只有得到这类样本，才可将现有历史线端点基准与真正独立的站间盲测分开，并验证 100 m 级贴合目标。
