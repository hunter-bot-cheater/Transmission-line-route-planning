## 本轮范围

## A* 正确性修复

普通 A* 原先把栅格最小代价 0 人为抬高到 `1e-6`。在存在零代价走廊时，这会让启发式高估到终点的剩余代价，A* 可能先返回成本更高的路径。

用 3×22 合成栅格复现：顶行代价为 0，中间行内部代价为 `1e-7`，底行不可通行。旧实现返回中间行，累计代价约 `2e-6`；Dijkstra 找到的顶行路线代价为 0。修复后启发式乘数使用栅格真实最小值，允许为 0。

当启发式为 0 时，A* 使用到目标的八邻域几何距离作为同一 `f=g+h` 值下的次级排序键。该距离没有加入 `f`，也没有用 epsilon 扰动主优先级，因此只影响等 `f` 状态的展开顺序，不改变最优性。80×160 全零合成栅格上，修复后从 `(40,5)` 到 `(40,154)` 弹出 150 个节点并得到零代价路线。

普通 A* 与带转弯惩罚 A* 都以目标几何距离作为等 `f` 次序键。后者此前在零代价栅格上因次序键也为零而退化为大范围扩展；新增 32×64 全零回归场景，要求保持 60 点直线路径且堆弹出数少于路径点数的两倍。

验证：新增回归测试覆盖普通 A* 零代价反例、零代价搜索扩展、转弯惩罚零代价性能，以及零最小成本/正路线成本/各向异性间距下与 Dijkstra 的转弯目标一致性。完整测试结果以本文件末尾的本轮校验记录为准。

## 约束语义边界

独立审查确认官方灾害掩膜当前只进入软代价。合成栅格把所有像元都设为灾害区时，代价仍有限且 A* 会正常穿越；这是现有设计的“避让偏好”，不等于法定禁建区。硬掩膜来自 DEM NoData、建筑足迹及用户显式硬约束，地形坡度/海拔阈值和建筑净距也仅在配置时启用。需要作为禁行条件的保护区、管制区或不可跨越面，必须以有来源和日期的硬约束图层明确输入；未知和不完整图层仍应标成未核实。

## 开源路线方法复核

开源方案里最贴近架空输电线路塔位优化的是 [LION](https://github.com/NinaWie/lion) 及其[优化框架论文](https://arxiv.org/abs/2101.03388)：把候选塔位建成图节点，把满足档距范围的线路段建成边，并区分塔位成本、线段成本、转角成本，生成多条差异化路径。LION 采用 GPL-3.0，代码和 `lion-sp` 发布较旧；先借鉴图模型，不直接拷入当前产品。

[PowerPlanner](https://github.com/NinaWie/PowerPlanner) 将栅格候选位置建成图节点，按最小/最大塔距连接候选点，并区分边（线路）成本、点（塔位）成本和转角成本；仓库标 MIT、自述为硕士研究代码，适合作为独立原型和算法对照，不能替代弧垂、净空和荷载校核。[PYORPS](https://github.com/marhofmann/pyorps) 的 README 仍以地下电缆和配电规划为主；0.4.0 已列出 overhead tower fields、corridor graphs 与多指标路由，但具体功能状态应按[官方 release status](https://pyorps.readthedocs.io/en/latest/)逐项核实，不能把字段/接口存在视为稳定的架空线设计功能。[PowerLine-GIS](https://github.com/samarthiith/PowerLine-GIS) 与[配套高压线路多准则论文](https://www.mdpi.com/2220-9964/8/8/316)可作成本层和事后评估参考，但仓库已归档，数据覆盖欧洲且栅格较粗，不适合直接移植台湾结果。[GRASS GIS `r.cost` / `r.path`](https://grass.osgeo.org/grass-stable/manuals/r.cost.html) 可用于独立复核栅格累计代价。[ATLDP](https://github.com/carloskleber/atldp) 已有显式路线/角点、塔型、档距与弧垂张力模型，但其 README 明确表示数值算法尚未达到生产就绪，自动塔位优化仍在后续计划，且主要按巴西 NBR 标准建模、采用 GPL-3.0；可参考领域模型，不应当作本项目的自动选线或生产校核器。

这些方法可以扩大可比较的方案集合、改善工程约束表达，却无法仅凭地形确定一条历史线路的真实选线原因。居民征地、路权、既有走廊、施工组织、勘测版本和业主偏好没有进入数据时，替换 A*、加 AI 或调权重都不能从现有地形唯一还原历史线路。[2019 年架空线规划研究](https://www.sciencedirect.com/science/article/pii/S037877961930272X)把走廊搜索、转角/候选点优化与塔位布置分开处理，说明合理的下一步是从像元 A* 过渡到“走廊—候选塔位与跨度图—纵断面塔位校核”；其巴西电压等级和工程参数不能直接套用台湾线路。

## 后续无先验消融与评测协议

1. 已将 `--terrain-slope-weight` 与 `--roughness-weight` 暴露为可记录的筛查参数，默认仍为 `0.75` 和 `0.25`，保证原基线代价不变。先做地形坡度项开/关 × 相邻边坡权重 `{0, 0.5, 1}` 的 2×3 消融；固定粗糙度、TPI、OSM、灾害权重和硬掩膜。随后再单独检验粗糙度、TPI，避免同时改多项而无法归因。
2. 地形配置冻结后，逐项比较居民软权重 `0/2`、官方灾害软权重 `0/1`、土地覆盖 `0/1`，再跑一组组合交互；灾害数据覆盖不完整时标记为未核实，不得解释为无风险。转弯权重 `0/0.25/1` 单独测试。
3. 固定 DEM 哈希、分辨率、端点、输入图层快照、硬约束和版本；先选平原、丘陵、陡山及建成区混合的代表线做筛查，再冻结少量候选跑全量。至少分别保留 A* 原始搜索线与平滑后的导出线，报告硬约束违规数、长度/直线比、坡度/爬升、建筑和灾害暴露、转角、运行时间及参数扰动下的几何稳定性。
4. 代价层权重仅依据预先定义的地形和工程筛查目标选择，真实线路只在版本冻结后做盲后验评测。空间对照同时报告双向 P95、双向均值、100/500/1000 米覆盖率、长度差、采样 Hausdorff 和图形；F1、固定采样 Hausdorff、离散 Fréchet、缓冲区 IoU 各有分辨率/覆盖偏差，不能单独作为“达标”结论。配对 SHP 内部一致性已核对，但尚无官方 ID、来源 URL、版本日期和精度证明，文案称“配对参考线偏差”更准确。

评测图标题已改为“配对参考线空间偏差”，不再硬编码 20 米 DEM；双向较差方向 P95 放在首位，F1@100 米标成覆盖诊断。

开源方法与本项目的差距进一步明确：A* 或 Dijkstra 解决的是代价栅格上的初始走廊，不会自动得出杆塔位置，也没有线路纵断面、电导线弧垂/张力、风荷载、塔型适用图表和净空约束。2019 年[路线与塔位联合优化研究](https://www.sciencedirect.com/science/article/pii/S037877961930272X)给出的流程是“栅格路线指引 → 图上选转角/候选塔位 → 纵断面动态规划排杆”；PowerPlanner/LION 是可参考的塔位图搜索原型，ATLDP 可参考电气机械模型但明确未到生产级。下一阶段应新增“候选塔位图 + 最小/最大档距 + 转角成本”实验模块，且把档距/电压/导线/塔族/净空作为项目输入；缺少参数时只做初始走廊筛选，不给未经证实的默认塔位设计。任何历史参考线仍只在冻结后评分，不能用于候选筛选、搜索范围或参数选择。

官方饮用水保护区和海洋野生动物重要栖息环境图层已经加入获取脚本并生成软约束 GeoJSON；该 12 线基线没有启用该用户 GeoJSON，因此本次指标不能声称这些新图层提升了贴合度。海保署当前 GeoJSON 把 EPSG:3826 坐标标成 CRS84，脚本只在范围符合预先验证的台湾 TWD97 TM2 坐标范围时覆盖 CRS 并重投影到 WGS84。海洋栖息地与水源保护区在模型里按软风险/许可筛查，不等于一律禁建区。

## TW252 建筑端点误阻断修复

OSM 建筑栅格使用 `all_touched=True`，建筑只要触到端点像元边缘，就可能把一个实际落在建筑外的站点挡住。当前实现只允许极窄的端点例外：端点像元只能被建筑足迹这一层挡住、建筑净距必须为 0、精确端点和端点到像元中心的短连接都不能与已映射建筑面相交、短连接不得触碰其它禁行像元。只重新开放该端点像元；规划完成后再用完整硬掩膜检查导出折线，并用可用建筑面精确检查整条线路。出现任一相交、其它硬约束阻挡、越界、无有效建筑几何或几何无效时仍拒绝任务。

这处理的是栅格触碰导致的端点误报，不补足 OSM 建筑覆盖，也不把可用建筑面当作完整建筑清单。

## 平滑候选代价回退

复核发现原路径平滑后只验证硬掩膜，可能把折线从低代价通道拉入高代价像元。现在 CLI 在输出平滑候选前，使用同一栅格的分段积分代价、DEM 地面高差项和配置的转弯项比较平滑前后目标值；候选硬约束不合法、目标值增加或无法评估时，回退原始搜索折线。该检查不改变 A* 搜索和代价权重，也不使用参考线路。

合成用例分别验证“跨入高代价带时回退”和“等代价直线可保留”；随后用 TW252 正式 real-case CSV 复跑，结果完整、无失败/无路，端点与输入坐标一致，栅格硬约束违规 0、已加载建筑相交 0。盲评仍为双向均值 5.596 km、较差方向 P95 10.430 km、F1@100m 1.39%、长度差 0.615%，与原结果相同。单例验证平滑保护没有恶化路径目标，但没有降低与历史线的巨大几何差距。

## 线路端点、风险统计与多候选审计

非站点任务过去只在触发建筑像元例外时恢复精确输入端点，正常端点可能停留在 DEM 像元中心。本轮统一恢复起终点坐标；恢复后重新应用地面坡度筛查、栅格硬约束检查，并在建筑图层可用时对已加载建筑几何做相交检查。结果 JSON 记录恢复了哪些端点像元、建筑图层覆盖状态及检查范围；“通过”只表示未触及当前已加载的 OSM 要素，不能证明该区域没有未映射建筑。建筑相交数现在统计全部相交要素。

新增的权重无关暴露向量用 `all_touched` 栅格化线路，分母是被线路触碰的栅格数，属于近似比例而非按线路长度加权。OSM 统计标明是映射要素清单；可用图层但覆盖未核实时，零值不能解读成没有居民或建筑。官方灾害覆盖状态不是 `complete` 时，暴露比例返回空值；正像元数标为已加载掩膜中的观测计数。缺失数组与网格尺寸不一致会明确报告为空或报错，不会用零数组伪造零暴露。

另外新增未接入 CLI 的多路径原型，用线路段几何计算距离，端点缓冲后要求两条线路至少有 70% 的内部线路长度达到分离阈值；像元间距必须显式提供，默认阈值按像元尺度计算。后续已补入生产 A* 的 DEM 高程、相邻地面坡度惩罚与上限、转角权重、像元实距和启发权重透传；首条基准路线与生产 A* 同参，候选的未扰动目标按原始栅格、高程和转角项重算，空间分离惩罚只用于备选生成。它仍没有杆塔档距、导线净空和矢量禁区完整校验，也未接入 CLI 的最终路线复核与导出，目前仅是合成实验，不代表真实误差改善。

## 2026-10-24 后续迭代：v4 指标与目标一致性

指标审计发现重复或部分重叠的参考线部件会在 v3 中重复增加覆盖权重，虽然缓冲区 IoU 已先合并几何。本轮将所有参考线经度统一到同一日期线分支，在源坐标平面上空间合并后再投影，按唯一中心线长度计算距离、分位数、覆盖率和总长度；有重复、部分重叠或拆分节点的输入可能因此改变计量口径。合并后仅有一条开放线时才计算端点和 Fréchet，断开的多线和闭环不定义这两项。指标版本升至 v4。新增公开 `compute_deviation` 端到端回归，覆盖碎片化线段的弧长权重、长度不等时的对称均值、部分重叠、日期变更线，以及重复部件不得改变空间相似度。

走廊备选原型也完成了生产搜索目标对齐：可透传地形高程、相邻地面坡度惩罚与上限、转角权重、像元实距和启发权重；首条结果应与相同参数的生产 A* 一致，候选记录的基线目标包含原始栅格、地面坡度与转角代价，而搜索时的距离惩罚只改变候选生成。此模块仍未接入 CLI，也没有塔位、弧垂净空或许可模型，不应作为最终规划结果。

另修正两处批量鲁棒性边界：OSM 缓存中若非有限坐标的可定位包络完全落在当前请求范围之外，会计数并跳过；范围内或完全无法定位的非有限要素仍 fail closed。路线对比图的 DEM 与灾害层改为按相同源栅格块边界聚合，尾块不整除时保留，避免灾害像元落到相邻显示格或被采样漏掉。此图仅为概览，不改变搜索和评估栅格。
