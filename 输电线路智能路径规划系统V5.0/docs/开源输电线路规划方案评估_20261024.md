# 开源输电线路规划方案评估（2026-10-24）

## 结论

开源研究支持把架空输电线路建模为“可选塔位—可行档距—转角与跨越约束”的图问题，而不是只在栅格上连接两个端点。它能改善工程变量表达，但不会自动复现一条历史线路；地形与公开约束未包含的征地协商、审批、既有通道和设计变更仍会形成不可观测差异。

本项目将真实线路只用于路线生成后的盲评，不把参考线几何、线路名称匹配结果或误差反馈输入搜索窗、成本层、参数选择和候选筛选。相似度作为诊断指标，当前不设固定覆盖率门槛。

## 开源方案与适用范围

| 方案 | 可借鉴内容 | 边界 |
| --- | --- | --- |
| [LION](https://github.com/NinaWie/lion) 与[论文](https://arxiv.org/abs/2101.03388) | 把候选塔位作为节点、可行塔间距作为边，联合优化阻力与转角，并生成差异化备选路径。与本项目的架空线路场景最接近。 | PyPI 发布版为 0.1.1（2021），仓库许可证为 GPL-3.0。先复用公开方法思想并自行实现/验证，不直接复制依赖；档距、塔位可建性和电气条件必须使用本项目可审计参数。 |
| [PYORPS](https://github.com/marhofmann/pyorps) | 高分辨率 GIS 成本面、多指标代价、路径和走廊分析；仓库当前 README 还列出 overhead tower fields，但功能状态需按其文档逐项核对。 | 工具起点主要是地下电缆 least-cost routing。不能据其栅格路径或实验性杆塔字段直接认定架空线工程可行；MIT 许可适合后续独立基准对照。 |
| [reVRt](https://github.com/NatLabRockies/reVRt) | 国家实验室维护的空间 least-cost routing，可编码选址禁限区、区域组件成本、土地构成成本、接入点成本和网络升级成本；同时提供 Python/Rust 路由实现。 | 面向新能源接网和输电成本/走廊筛查；不能替代台湾塔型、档距、弧垂和导线净空校核。适合作为代价面与大范围路径性能的外部对照，不宜直接替换整个应用。 |
| [Alliander Utility Route Planner](https://github.com/alliander-opensource/utility-route-planner) 与[2026 开源基准论文](https://doi.org/10.1007/s12667-026-00827-x) | Apache-2.0；提供 5 个真实地下配电电缆案例、成本准则、路线评估和可复现代码，可借鉴独立基准组织方式。论文报告其 least-cost 方案长度接近人工线路，但空间相似度多数偏低。 | 面向地下配电电缆，仓库明确不用于生产；自身也把“更像既有基础设施的路线”列为待解决问题。不能将案例数据或结论当作台湾架空输电验证。 |

| [ATLDP](https://github.com/carloskleber/atldp) | 参考线路显式 POI、塔型、弧垂张力、净空与结构校核的分层工程工作流。 | GPL-3.0；仓库自己说明数值模型仍在验证、目前不可用于生产设计。它不是可直接替换本项目路线搜索器的成熟规划器。 |

### 新增开源证据与选择

- **LION 的公开接口确实实现了多样候选与间距/角度约束。** 它接受二维阻力栅格，可计算最小转角最短路、`k` 条差异化路径，以及具有最小/最大点间距的点选线。LION 论文将节点解释为候选塔位、边解释为可行相邻塔跨距，并指出先做普通栅格选线再布塔可能造成后续塔位不可行。该仓库采用 GPL-3.0；本项目应先复现方法和评测，直接复用代码或增加依赖前先审查许可证兼容性。[LION README 与许可](https://github.com/NinaWie/lion)、[LION 论文](https://arxiv.org/abs/2101.03388)
- **PYORPS 近期增加了可借鉴的搜索基础设施。** 0.4.0 README 列出多指标目标、成本场复用、GPU 后端以及 overhead corridor graphs / tower fields；其中部分功能标记为 research/experimental，主定位仍是地下电缆。许可证为 MIT，适合做独立对照，但接入前需按 release-status 文档确认具体 API 稳定性。[PYORPS 仓库](https://github.com/marhofmann/pyorps)
- **不能把“长度接近”解释成“线路形状恢复成功”。** 2026 年电缆路由开放基准使用 5 个真实人工设计案例和多种空间评估指标。论文摘要报告路线长度可接近人工方案，但多数案例空间相似度偏低，复杂约束仍不足；Alliander 仓库明确列出既有基础设施对齐、人类路线形态和现实道路交叉为未解决项。虽然该基准是地下配电电缆而非架空输电，它仍说明几何贴合依赖数据和决策信息，换更快或更“聪明”的 shortest-path 算法本身并不能补齐它们。[论文摘要](https://research.wur.nl/en/publications/an-open-source-benchmark-of-the-state-of-the-art-in-electrical-ca/)、[基准仓库限制](https://github.com/alliander-opensource/utility-route-planner)
- **ATLDP 更像后段工程校核参考，而非自动走廊规划器。** 它公开了路线 POI、手动塔位、导线弧垂张力、净空与结构模型，并声明生产使用尚未就绪；其自动杆塔优化仍是后续阶段。项目为 GPL-3.0，适合参考工程阶段边界，不应直接嵌入当前软著项目。[ATLDP 当前范围与状态](https://github.com/carloskleber/atldp)

综合来看，没有发现一个可直接下载后就能解决“台湾站点到站点架空线路、只靠地形且精确复现既有线路”的开源项目。最可行的技术组合是：保留当前可复现 A* 作为栅格基线；用 LION 的候选塔位/转角/多样路径思想扩展现有实验图搜索；参考 reVRt/PYORPS 的可解释多层代价与可复用成本场；最终按真实站点、设计参数和地形剖面校核每个候选档距的弧垂、净空、跨越和塔型荷载。真实线路仍只在候选生成冻结后用于后验几何诊断。

## 本项目当前模型的差距

- A* 的决策变量仍是栅格路径，代价面主要由 DEM 地形因子、OSM 建筑/用地代理和官方灾害图层构成。
- 搜索没有塔位可建性、适用塔型、档距上下限、转角塔限制、导线弧垂/净空、风荷载、基础地质、跨越许可或权属协商等工程/审批变量。
- `35m` 是当前 DEM 的近似地面像元间距，不等同于垂直精度或测绘精度；官方灾害数据和 OSM 覆盖不完整时，“未观测到”不能解释为“没有风险”。
- 最近 12 例用于开发诊断，不是独立泛化集。参考线形状差异不能作为继续调权重的监督信号。

## 台湾公开工程规则的适用边界

公开法规没有提供可直接套用于所有台湾输电线路的统一最大档距。`輸配電設備裝置規則` 将线路安全要求落在具体的荷载、张力、弛度、净空和机械强度条件上；其中相对档距限制和局部支撑结构要求不能抽成通用输电塔档距上限。该规则也明确不是设计规范或指导手册。桃园市公开的单一 345 kV 工程案例提到常见档距量级和特殊长跨距，但它只描述该项目，不能代替线路设计资料。

因此，塔位图应保留“概念候选”标签，直到用户提供并核验适用电压等级、导线与塔型、风区/地形条件、设计张力、弧垂和净空规则。没有工程参数时，程序不应把任意经验档距称作合规或可施工。法规与案例来源：[全國法規資料庫《輸配電設備裝置規則》](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=J0030019)、[桃園市政府板橋—龍潭線說明](https://www.tycg.gov.tw/NewsPage_Content.aspx?n=10&s=310582)、[台電供電處人員塔型技術報告](https://report.ndc.gov.tw/ReportFront/PageSystem/reportFileDownload/C10203390/001)。

## 2026-10-24 固定基线复测

命令使用 35 米 DEM（最大边长 4096）、A* 基线、12 个真实线路案例、0.30°搜索窗口、关闭 VIN/PPO；规划代码只从站点端点和 DEM/约束栅格生成路线，真实线路在路线生成后用于评分。批次完整完成 12/12，无失败、无无路，12 条参考线均 100% 位于规划窗口内。结果文件位于 `outputs/real_recheck_35m_lex_030_20261024/`。

| 双向后验指标 | 12 例中位数 | 取值范围 |
| --- | ---: | ---: |
| 长度加权对称平均偏差 | 5.01 km | 1.04–12.14 km |
| 较差方向 P95 偏差 | 9.47 km | 3.05–22.08 km |
| F1@100m | 1.30% | 0.22–8.15% |
| F1@1km | 7.40% | 3.42–58.64% |
| F1@5km | 49.25% | 17.57–100% |
| 路线长度绝对差 | 3.08% | 0.33–26.10% |

这些结果显示，端点窗口和路线长度并不能保证走廊形状相似。这里的距离与覆盖率只用于冻结后的诊断，不作为规划目标、参数搜索目标或验收门槛；尤其在禁止历史路线先验时，不应靠调权重追逐这些分数。本轮也没有向 CLI 提供最小统计区/人口图层，因此该批次不能代表人口暴露成本已纳入。下一轮应先接入并核对独立的工程数据（塔位可建性、适用跨度与导线净空）及已下载的人口/敏感设施资料，再用固定参数做整批复测。

## 迭代路线

1. 保留 A* 作为可复现栅格基线，先完成本轮固定 12 例批次，比较双向几何偏差、路线长度、硬约束、风险暴露、坡度、数据覆盖和运行资源。
2. 将已有 `experimental_tower_graph.py` 接入一个显式 opt-in 的候选模式：仅对有限、可通行栅格建立塔位候选，档距边沿线积分成本并检查禁入栅格，转角代价只作用于塔位节点。它不参与最终路线选择，先和 A* 并行输出供评估。
3. 最小/最大档距不设通用默认值。台湾电压等级、导线、塔型和适用标准未确认前，必须由运行参数明确提供；缺少这些参数时，不把塔位图候选标记为工程可行。
4. 下一步分别增加塔基适宜性成本与档距沿线成本，避免把同一个地形栅格分数重复计入“塔位成本”和“跨越成本”。加入塔型/转角约束、纵断面和净空模型前，先取得可追溯标准和相应的地形/表面数据。
5. 对官方灾害与 OSM 图层输出覆盖/未知区暴露，保留“已知风险筛查”的语义；对资料缺失区域做显式情景或人工复核，不把未知直接编码为无风险。

## 评估约定

每个实验冻结输入数据校验和、代价参数、搜索窗、算法和软件版本。规划路线生成并冻结后才读取历史线路，报告双向长度加权距离分布、多个距离阈值覆盖率、路线长度差、塔位/档距/转角统计、约束违规、风险和覆盖完整度。历史线相似度只用于后验诊断，不用于选参、打分或选择最终路线。
