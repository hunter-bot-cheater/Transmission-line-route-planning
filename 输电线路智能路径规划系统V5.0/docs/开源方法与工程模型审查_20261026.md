# 输电线路开源方法与工程模型审查（2026-10-26）

## 结论

当前系统适合做地形和约束条件下的初步走廊筛查，现有证据不足以称为可施工的站间线路方案。更可信的技术路线是把“走廊搜索”和“塔位/导线工程筛查”分成连续的两层：先从地形和经核验的环境约束中产生多个候选走廊，再在候选图上放置转角点和塔位，并用适用的导线、荷载、弧垂及净空参数逐跨筛查。

## 开源方案审查

- Santos 等人的输电线路规划研究采用三段式流程：栅格 least-cost 搜索形成走廊，图搜索选择线路顶点，再用动态规划按地形纵断面布塔。该研究报告了巴西 525 kV 项目案例。它支持“走廊与塔位分层”的架构，但案例与台湾的规范、导线及地形条件不同，不能直接移植其参数。
- ATLDP 是 GPL-3.0 的开源架空线路电机设计/CAD 项目，覆盖塔位、弧垂、净空等相邻问题。其仓库当前明确说明数值模型仍属实验阶段，且不应用于生产设计；它可作为工程数据模型和可复现报告格式的参考，不作为本项目的现成工程认证器或直接算法依赖。
- 台湾《输配电设备装置规则》第 2 条说明规则的目的在人员与公众安全，并明确它不是设计规范或指导手册。路线筛查不能仅靠该规则构造塔距、导线弧垂或荷载参数；这些值必须来自适用的台电设计资料或项目工程输入。

## 对本项目的具体判断

`experimental_tower_graph.py` 已能在候选塔位图上筛查档距和简化抛物线弧垂净空，但模块文档明确不包含导线专属悬链线、荷载、许可或经验证的塔距标准。当前真实线路批次只比较地表栅格路径，没有运行塔位图，也没有已核验的站端接入点和导线工程参数。因此误差图只能描述给定端点下的几何相似度，不能证明真实站间可行性。

《输配电设备装置规则》可用于识别必须考虑的安全主题；台电公开的输电线路维护准则可以提示塔基环境风险和山区塔位管理主题，但维护阈值不应直接转成线路禁行规则。任何新增硬约束都应同时记录来源、适用范围、坐标基准、更新时间和核验凭证。

## 本轮代码调整与验证

实验 8/16 邻域 A* 与 Theta* 原先只在主代价严格下降时更新标签；平坦或相同风险区域中，同代价路径会由邻居遍历顺序决定。现改为按“主代价、路径长度”字典序更新，并把欧氏剩余长度作为次级下界。A* 的主目标仍是原来的积分代价，长度只在主代价相同时起作用。Theta* 仍不保证加权栅格上的全局最优。

实际 CLI 将搜索栅格设为 `1 + 4 × 风险代价`，所以真实批次的启发式下界为正；本次修正的动机是明确的同代价择短规则，而不是修复 CLI 搜索退化为 Dijkstra。

固定 10×10 零风险障碍图复现了择短差异：16 邻域 A* 路长从 13.416 m 降至 13.187 m，并与独立字典序 Dijkstra 结果一致；Theta* 路长从 13.456 m 降至 13.074 m，且候选折线逐段可通行。该合成结果证明了平手处理，不代表真实线路精度改善。

服务器 venv 中定向运行了 `test_experimental_astar_16.py`（8 项）和 `test_experimental_theta_star.py`（10 项），均通过。代码已提交并推送至 `codex/station-route-hardening`，提交 `8b9171a1deb2a22032d027a9224900a88ed802fe`。
