# 输电杆塔公开数据审计（2026-10-24）

本次检查只判断公开数据能否支撑候选塔位路由，不将线路或杆塔几何作为规划先验。

## 台电全台电杆坐标

- 来源：[政府资料开放平台数据集 33305](https://data.gov.tw/dataset/33305)，提供机构为台湾电力公司；平台列出的字段包括县市、行政区、乡里、图号坐标、形式、杆号和 TWD97 X/Y，更新频率标为每月。
- 资源 `all.csv` 的 HTTP 头显示 319,982,717 字节。本次只用 Range 读取文件头 4,096 字节并核对字段，没有下载全量文件。
- 数据集范围是全台电杆，字段没有明确线路资产 ID、电压等级、塔型、档距或可建塔许可。因此无法区分哪些点属于待规划输电回路，也不能将全部电杆作为候选塔位或线路吸引项。

## 台南市 110 年输电系统电杆 SHP

- 来源：[台南市政府资料开放平台资源页](https://data.tainan.gov.tw/Resource/f5f7257d-418f-4972-811b-a082635daca8)，页面标注数据名称为“110 年输电系统电杆”、范围为台南、ShapeFile、开放政府资料授权；资源发布日期为 2022-06-27，资源元数据更新日期为 2025-12-29。
- 临时下载并读取 SHP 后得到 343 个点要素。文件没有 `.prj`，平台的地理坐标系统字段为 `0`；数值范围看似经纬度，但 CRS 未得到权威确认。
- 属性含 `CatCode`、`Agency`、`PoleNo`、`Length`、`Material`、`UseStat`、`Status` 和 `Notes`，没有线路 ID、电压等级或塔型设计参数。记录中 339 个材料值为“水泥桿”，`Notes` 中仅 2 条含“电塔”；这不足以证明数据覆盖了某条完整输电线路或可供线路规划使用。

## 接入结论

两份资料暂不进入规划器，也不用于误差调参。台电全台电杆数据可能用于后续资产候选的初筛，但必须先取得字段字典及输电资产关联；台南 SHP 需确认 CRS、覆盖完整性、杆塔分类和线路归属。能支持真实候选塔位规划的最小数据仍是：独立站端接入点、线路资产 ID/电压等级、核验过的杆塔/档距或设计参数，以及可建塔约束。拿到这些后，可先做影子测试，参考线路只在规划完成后用于评估。

### 官方目录复核（2026-10-25）

- [台电电杆坐标及杆号数据集 33305](https://data.gov.tw/dataset/33305) 的目录仍列出县市、行政区、乡里、图号座标、形式、杆号、`TWD_97_X/Y`，更新频率标示为每月；这些字段能描述电杆位置，但目录没有线路资产 ID、电压等级或输电回路关联，不能据此筛出目标高压线路的塔位。
- [“高压电塔位置资讯”开放数据建议 17292](https://data.gov.tw/suggests/17292) 是需求建议页面，建议字段包括高压电位置坐标和管理单位，实际派发机关为经济部。页面虽显示已回复，但没有可读取的回复正文或数据资源链接；它证明有人提出开放需求，不证明政府没有内部数据，也不能作为塔位数据源。
- 台北市另公开局部输电管线和场站 XML；要素与匹配问题见[台北输电系统公开图层核查](台北输电系统公开图层核查_20261025.md)。该数据有实际线几何，但站点 ID 不连接线路端点、市府标注仅供参考，因此只保留为局部事后参考，不改变全台端点/杆塔数据缺口结论。

因此当前结论仍是：公开的通用电杆点不能替代经核实的输电塔位网络；在取得线路归属和工程参数前，不把它们接入寻路或用于验证工程可建性。
