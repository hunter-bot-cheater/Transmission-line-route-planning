## 修改

- 新增可选 `--land-mask-geojson`，接受 WGS84 GeoJSON `Polygon`/`MultiPolygon`；多边形内部像元中心可通行，外部像元进入硬约束掩膜。
- 使用像元中心判定，避免 `all_touched` 把与边界相碰的海域像元误放行。
- 对各组成部分本身有效、但因嵌套或重叠而整体无效的 `MultiPolygon` 执行溶解；无法安全修复时停止并报错。
