# 官方 2025 20 m DTM 镜像来源审计

日期：2026-10-24

范围：只审查公开数据源、衍生文件和来源完整性；未读取历史线路、参考线路或误差结果，未修改规划算法。

## 结论

找到可访问的 2025 DTM 衍生镜像：Hugging Face 数据集 [yhzkiki/taiwan-dtm-2025-terrarium-z13](https://huggingface.co/datasets/yhzkiki/taiwan-dtm-2025-terrarium-z13)，固定版本 `8ae5c06ae126ca8e01d02928260f512d713a0be8`。镜像发布了 Terrarium RGB XYZ 瓦片和重建脚本，不是原始 GeoTIFF。其来源清单给出官方 ZIP/TIFF 的 SHA-256，但本轮无法从官方 TGOS 下载原文件，因此这两个主岛哈希仍是第三方声明，没有独立复验。

**不把 Terrarium 瓦片接入规划器。** 重建脚本将官方 NoData 转成 0 m，并对所有矩形覆盖瓦片填充输出。全量索引中 4,166 张瓦片有 2,100 张没有任何有效源像素、401 张只有部分有效像素；仅凭 RGB 瓦片无法区分真实 0 m 与伪造海平面，也没有可用于还原的逐像素 NoData 掩膜。这个处理会在候选路径代价中产生虚假的平地。应优先取得原始 GeoTIFF，再保留 NoData 掩膜后做坐标/分辨率统一。

## 来源链及验证结果

1. 官方目录 [data.gov.tw 数据集 176927](https://data.gov.tw/dataset/176927) 将该数据描述为内政部地政司发布的 2025 版 20 m DTM，免费，适用政府资料开放授权第 1 版；页面用途描述为地形显示与粗略分析。该目录的下载 CSV 指向官方 TGOS 产品。
2. 官方目录 CSV 的公开缓存（[shadowjohn/dem20M_terrain](https://github.com/shadowjohn/dem20M_terrain)，2026-05-25 生成）记录主岛链接：`https://www.tgos.tw:443/MDE/VirtualDir_TC/Product/528530be-0710-431e-954e-2f2f5e98b0c5/不分幅_全台20MDEM(2025).zip`。本机对 percent-encoded 直链执行 HEAD 得到 **403 Forbidden**，未下载 ZIP/TIFF。上游 moidemd README 也记录 TGOS 对非台湾来源 IP 返回 403。
3. Hugging Face 数据集卡和 `source-manifest.json` 都标注官方数据集 176927。来源清单声称主岛 ZIP `2e1cd738b3c3abbcfdbce79ac18a5818a6ec80aa32c2813f0e21cfd909be295c`、TIFF `59e5e980000d6e3f5a7734c6af197934a1a5432482b6caa789a1ec90b624015d`。本次只确认清单文件与瓦片来自所固定的 HF commit；因原 ZIP/TIFF 不可访问，未验证清单中的原始文件哈希。
4. 镜像的澎湖/金门 TIFF SHA-256 与另一个开源项目 [outdoorsafetylab/moidemd 的下载器](https://github.com/outdoorsafetylab/moidemd/blob/master/scripts/fetch-dem.py)里登记的值相同。这是独立项目间的哈希记录交叉印证，不等同于对官方原始文件字节的独立校验。官方原件没有下载到本机。

## 空间与高程属性

来源清单声称本岛 GeoTIFF 为 10,035 × 18,852、Float32、20 × 20 m、NoData `-32767`、EPSG:3826，WGS84 范围约 `[120.016566054, 21.893851162, 122.009647727, 25.301472986]`；澎湖与金门使用 EPSG:3825。这里的分辨率、CRS、范围均是第三方清单记录，未能从原始文件独立读取。官方目录记录平面坐标和高程，但没有在本轮可读取的原件中确认垂直基准；另一个项目的 README 声称 TWVD2001，但在取得原始 TIFF/Metadata.xml 前应记为**未核实**。

镜像脚本将输入重投影到 EPSG:3857，使用 bilinear 插值，再编码为每通道 RGB 的 Terrarium 高程；量化步长为 1/256 m。z13、台湾纬度 22–25°时 Web Mercator 地面像元约 17.3–17.7 m，接近原始 20 m 网格；像元尺度本身没有 4 倍过采样问题，但重投影插值仍改变了原始采样值，且 NoData 掩膜已经丢失。

官方目录的开放授权为 OGL v1。HF 数据集的结构化 license 字段为 `other`，但其 README 声明原始数据采用 OGL v1，并要求保留官方来源和授权信息。再分发时应保留官方数据集链接与授权说明。

## 内政部 DTM 官方 OpenAPI 点值/剖面能力

官方平台主页的“API说明文件”链接会跳转至 [DTM OpenAPI Swagger](https://dtm-openapi.colife.org.tw/swagger/index.html)；对应 v1 规范已保存到被 Git 忽略的 `data/official_sources/dtm_moi_openapi_audit/swagger-v1.json`，SHA-256：`d85959877f7fdc30d0217c9d411ae7c6fbe94e3360e74795e222b2152338791c`。官网说明 20 m 介接服务为开放资料、无需申请；但 OpenAPI 对查询端点仍要求 `api_key` 路径参数，并称其为服务单位发给的认证码。本轮没有可用密钥，也没有申请/复用任何密钥。

规范提供以下可用于独立查询的接口：

- `GET /api/Polate/getSinglePolate/{wkt}/{data}/{api_key}`：单点近似高程。
- `GET /api/Polate/getMultiPolate/{wkt}/{data}/{api_key}`：多点近似高程。
- `GET /api/PathProfile/getPathProfile/{wkt}/{data}/{api_key}/{stepSizeValue}`：路线剖面；响应包含沿线距离 `m` 与 `x/y/z`。

OpenAPI 的数据枚举没有 2025 版代码。20 m DTM 代码名称包括台湾 `2001-2006`、`2011-2016`、`2010-2019`，澎湖 `2010-2019`，金门 `2016-2017`。代码名中的日期是规范可确认的年份标识；该规范未说明这些日期究竟代表测制、资料汇入或发布区间，不能据此声称年份定义已核实。`PathProfile` 的枚举仅包含台湾 `2001-2006`、`2011-2016` 等层，未列点值接口所见的 `2010-2019` 代码；没有 2025 年层可供本轮同年代核验。

只读连通性探测使用与线路无关的公开城市坐标样本：台北 `(121.5654,25.033)`、台中 `(120.6736,24.1477)`、高雄 `(120.3014,22.6273)`，另以 Swagger 公开示例的 `LINESTRING` 测试剖面。有效 WKT、可用数据代码配上字面值 `test`（仅 dummy，不是凭证）后，点查和多点查返回 HTTP 400 `{"error":"API KEY 錯誤"}`；有效的旧版剖面数据代码也返回同一认证错误。空 key URL 返回 404。没有取得任何高程数值或剖面结果。改用 `2010-2019` 代码请求 `PathProfile` 得到 `輸入參數錯誤`，与该代码不在此 endpoint 的枚举中相符。

规范说明系统使用 WGS84 经纬度，但响应 schema 只列 `x/y/z`，未声明 Z 单位/垂直基准；也没有随结果返回数据版本/栅格元数据。故即使获得 API key，它可用来做点值/剖面的独立旧数据参照，却不能作为 2025 DTM 的同年代真值，垂直基准也需另行向数据提供方确认。

**接入建议：不接入规划器。** 若以后取得正式 API key，可在不使用历史线路的前提下抽取固定公开点做旧版地形的 QA 参照；只有明确具体数据版本并核实 Z 基准后，才适合与本地高程做数值差异解释。现阶段它不解决原始 2025 DTM 尚未下载/验证的问题。

复现记录和探测响应摘要保存在 `data/official_sources/dtm_moi_openapi_audit/probe-results.json`。规范链接：[官方 DTM 平台与介接说明](https://dtm.moi.gov.tw/)、[官网 API 文档入口](https://dtm.moi.gov.tw/Home/APIDocument)、[OpenAPI JSON](https://dtm-openapi.colife.org.tw/swagger/v1/swagger.json)。
