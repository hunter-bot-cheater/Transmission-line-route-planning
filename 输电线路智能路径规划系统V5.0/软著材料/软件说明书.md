# 输电线路智能路径规划系统 V5.0 软件说明书

## 文档用途与软件定位

本说明书对应当前工作区中冻结的 V5.0 软件包，供软著申请材料准备及软件使用说明。软件以固定起点和终点为输入，读取数字高程模型及可选的土地、建筑、灾害和自定义约束图层，生成输电线路走廊筛查路线。默认规划方法为确定性 A*；路线相似度只在候选路线冻结后作独立事后评估，不参与路线搜索或选优。

软件输出属于规划前期筛查结果，不替代线路侧接入点测绘、环境影响评价、现场勘查、电气设计、塔位与档距校核、跨越许可或工程审查。当前登记申请尚需著作权人、开发完成日期、发表状态及权属证明等事实信息。

## 运行环境与安装

当前代码在 Windows 工作区编辑，并在 Linux 服务器 CPU 环境完成路线批量计算。核心 A* 规划不依赖 GPU。可选 VIN/PPO 诊断代码需要 PyTorch；它们不作为默认最终路线来源。依赖以项目根目录 requirements.txt 为准，栅格地理处理使用 NumPy、SciPy、Pandas、Rasterio、GeoPandas、Shapely、PyProj 等库。

```text
python -m venv .venv
pip install -r requirements.txt
python -m transmission_path_planner --help
```

数据规模、栅格边长、邻域方式和可选图层会影响计算时间与内存占用。建议先使用较小区域验证输入坐标、坐标参考系、NoData 与约束覆盖情况，再运行较大范围任务。

## 输入数据

| 输入 | 用途 | 重要校验 |
|---|---|---|
| DEM 栅格 | 高程、坡度、粗糙度等地形代价与筛查 | 检查坐标参考系、垂直基准、NoData、分辨率及覆盖范围 |
| 站点表和站间任务表 | 以站点/线路接入点指定起终点 | 正式任务要求两端声明线路侧接入点已核验，并记录来源和凭证；软件只校验声明字段，不验证证据真伪 |
| 自定义约束 GeoJSON | 配置硬约束或带权软约束 | 坐标系须按接口要求提供；核实来源、时间和适用范围 |
| 土地、建筑、灾害图层 | 构建筛查掩膜或软代价 | 图层缺失、覆盖不完整或 NoData 不得解释为无风险 |
| 人口栅格（可选） | 提供人口暴露代理成本 | 默认关闭；模型估算与重采样不提高原始数据精度 |
| 历史线路（仅评估） | 候选冻结后的空间偏差评估 | 不进入规划输入、调参或选路 |

## 主要处理流程

1. 读取 DEM 和可选图层，检查栅格范围及输入声明。
2. 建立规划窗口、硬约束可通行掩膜和软代价栅格。
3. 默认以确定性 A* 搜索低累计栅格代价路径；可选转弯代价 A*、加权或实验性搜索用于对照。
4. 对路径进行约束感知平滑与地理坐标转换。
5. 输出候选路线、运行摘要、约束检查和可视化结果。
6. 如需对历史路线进行研究评估，应先冻结候选坐标和哈希，再单独计算双向空间偏差及容差覆盖率。

## 输出内容

每个规划任务可输出候选路线 GeoJSON、运行日志/摘要、路线指标和比较图。具体文件名随参数与运行目录变化。路线输出中的约束状态只表示程序检测到的已配置图层，不代表外部审批或工程安全认证。

## 当前验证范围与限制

截至 2026-10-27，已完成 3 个固定端点案例的 18 组地形代价权重消融，以及 3 个案例、5 个转弯权重水平的 15 条候选路线事后对比。转弯权重实验中 12 条新增路线在服务器 CPU 上运行成功；GPU 未使用。15 条候选的双向较差方向 P95 为 3.026–9.095 km，100 m 对称 F1 为 1.401%–2.222%，没有候选达到 100 m P95 目标。此结果只覆盖三个样例，不能代表所有线路。

转弯权重目前同时作用于搜索和路径平滑，因此该批次测量的是端到端联合变化，不是单独的 A* 搜索效应。三个案例的起终点来自历史线路端点，尚未全部核验为变电站线路侧接入点。实验通过已配置硬约束检查，不等于工程可建性判断。

塔位图、固定挂点、弧垂和净空模块仍为实验筛查模型；当前资料不足以证明实际导线力学、塔型、风冰荷载和法规净空均已建模。软件不宣称达到历史线路 100 m 贴合或工程设计标准。
